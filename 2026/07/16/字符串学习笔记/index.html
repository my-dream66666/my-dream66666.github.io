字符串学习笔记

前言

此文主要讲解一些基础的字符串算法以及进阶字符串算法。

KMP

KMP 算法用于字符串匹配，具体来说，就是看字符串 TTT 与字符串 SSS 的哪些子串相同。并且我们称 SSS 为文本串，TTT 为模式串。

这里会有一个重要的概念——border：一个字符串 TTT，满足 TTT 既是 SSS 的前缀，又是 SSS 的后缀。下面说的 border 通常是最长 border，请自行甄别。

有个小定理：border 的 border 仍然是原串的 border，稍加思考即可得到。

这样在 KMP 的过程中，如果下一个字符不匹配，根据我们原来匹配的信息，就要从已经匹配的字符串的 border 开始，因此我们要求出模式串每个前缀的 border。

假设已经求出了 TTT 的前 iii 个前缀的 border，需要第 i+1i+1i+1 个。

  1. 最简单的情况是，从第 iii 个前缀的 border 开始能继续匹配一个，那么 i+1i+1i+1 的 border 就是 iii 的 border 加 111。

  2. 否则，则从 border 的 border 开始，直到能匹配下一个位置。如果 border 变成了空串也不能匹配下一个，那么第 i+1i+1i+1 个前缀的 border 就是空串。

求出 TTT 的所有前缀的 border 后，如果 TTT 与 SSS 的下一个字符不能匹配，就从 TTT 已经匹配部分的 border 继续，这个过程与求 TTT 的 border 是一样的。

在代码实现中，我们用 nexnexnex 来表示 border，nexinex_inexi​ 是指如果第 iii 个字符不能匹配，那么就从 nexinex_inexi​ 继续比较，这样实现可以方便跳转、比较，简化代码。

所以 TTT 的第 iii 个前缀的 border 就是前 nexi+1−1nex_{i+1}-1nexi+1​−1 个字符。

Manacher

Manacher 和 border 没有太大关系，但是与一种思想：根据已知信息来加速求未知，息息相关。
