题解：P3349 [ZJOI2016] 小星星

前言

题目传送门。

比较妙的一道题。此题作为我省选容斥和反演的开端。

▶
题目

题目描述

小 Y 是一个心灵手巧的女孩子，她喜欢手工制作一些小饰品。她有 nnn 颗小星星，用 mmm 条彩色的细线串了起来，每条细线连着两颗小星星。

有一天她发现，她的饰品被破坏了，很多细线都被拆掉了。这个饰品只剩下了 n−1n-1n−1 条细线，但通过这些细线，这颗小星星还是被串在一起，也就是这些小星星通过这些细线形成了树。小 Y 找到了这个饰品的设计图纸，她想知道现在饰品中的小星星对应着原来图纸上的哪些小星星。如果现在饰品中两颗小星星有细线相连，那么要求对应的小星星原来的图纸上也有细线相连。小 Y 想知道有多少种可能的对应方式。

只有你告诉了她正确的答案，她才会把小饰品做为礼物送给你呢。

输入格式

第一行包含 222 个正整数 n,mn,mn,m，表示原来的饰品中小星星的个数和细线的条数。

接下来 mmm 行，每行包含 222 个正整数 u,vu,vu,v，表示原来的饰品中小星星 uuu 和 vvv 通过细线连了起来。这里的小星星从 111 开始标号。保证 u≠vu\neq vu=v，且每对小星星之间最多只有一条细线相连。

接下来 n−1n-1n−1 行，每行包含 222 个正整数 u,vu,vu,v，表示现在的饰品中小星星 uuu 和 vvv 通过细线连了起来。保证这些小星星通过细线可以串在一起。

输出格式

输出共 111 行，包含一个整数表示可能的对应方式的数量。

如果不存在可行的对应方式则输出 0。

输入输出样例 #1

输入 #1

输出 #1

说明/提示

对于 100%100\%100% 的数据，n≤17n\leq 17n≤17，m≤12n(n−1)m\leq \frac 12n(n-1)m≤21​n(n−1)。

题意简述

给你一个 nnn 个点 mmm 条边的无向图，再给你一棵 nnn 个点的树，问有多少种点编号的映射方式，使得 nnn 个点恰好匹配，且树上的边均存在于原图中。

n≤17n\leq 17n≤17，m≤12n(n−1)m\leq \frac 12n(n-1)m≤21​n(n−1)

解决方法

初步 DP

令 fi,j,Sf_{i,j,S}fi,j,S​ 表示第 iii 个点对应第 jjj 个点，iii 的子树对应的集合为 SSS 的方案数，由于需要枚举子集，时间复杂度为 O(n33n)\mathcal O(n^3 3^n)O(n33n)，可以用多项式科技优化子集卷积做到 O(n42n)\mathcal O(n^4 2^n)O(n42n)（目前我还没学），但还是过不了。

发现枚举子集是必要的，然后基本上就没有优化空间了，因此我们需要用另一种方式。

再探 DP

枚举子集因为我们需要保证每个点对应的数不能重复，但是我们令 fi,j,Sf_{i,j,S}fi,j,S​ 为点 iii 对应 jjj，其子树对应的集合恰好为 SSS 的方案数。由于是恰好，所以 f1,j,2n−1f_{1,j,2^n-1}f1,j,2n−1​ 对应的就是一个排列，即我们的答案。

但是我们发现恰好的限制太紧了，还是不好求，因此可以想到利用反演将其转化成至少。于是就有令 gi,j,Sg_{i,j,S}gi,j,S​ 表示点 iii 对应 jjj，其子树对应的集合是 SSS 的子集，即至少为 SSS 的方案数。

所以我们就有：

gi,j,S=∑T⊆Sfi,j,Tg_{i,j,S}=\sum_{T\subseteq S}f_{i,j,T} gi,j,S​=T⊆S∑​fi,j,T​
