题目

题目描述

已经使 Madoka 有签订契约，和自己一起战斗的想法后，Mami 忽然感到自己不再是孤单一人了呢。

于是，之前的谨慎的战斗作风也消失了，在对 Charlotte 的傀儡使用终曲——Tiro Finale 后，Mami 面临着即将被 Charlotte 的本体吃掉的局面。

这时，已经多次面对过 Charlotte 的 Homura 告诉了学 OI 的你这样一个性质：Charlotte 的结界中有两种具有能量的元素，一种是“糖果”，另一种是“药片”，各有 nnn 个。在 Charlotte 发动进攻前，“糖果”和“药片”会两两配对，若恰好糖果比药片能量大的组数比“药片”比“糖果”能量大的组数多 kkk 组，则在这种局面下，Charlotte 的攻击会丟失，从而 Mami 仍有消灭 Charlotte 的可能。

你必须根据 Homura 告诉你的“糖果”和“药片”的能量的信息迅速告诉 Homura 这种情况的个数.

输入格式

第一行两个整数 n,kn,kn,k，含义如题目所描述。

接下来一行 nnn 个整数，第 iii 个数表示第 iii 个糖果的能量 aia_iai​。

接下来 nnn 个整数，第 jjj 个数表示第 jjj 个药片的能量 bjb_jbj​。

保证上面两行不会有重复的数字。

输出格式

一个答案，表示消灭 Charlotte 的情况个数，需要对 109+910^9+9109+9 取模。

输出 #1

容易将题目转化成 a>ba>ba>b 的配对有 n+k2\frac{n+k}{2}2n+k​ 个，套路地将 a,ba,ba,b 排序。

发现普通的 DP 很难办，因为如果计算 a>ba>ba>b 的配对个数，就无法兼顾剩下的数一定是按 a<ba<ba<b 来配对的。因此我们很容易想到松弛限制。

我们求的是 hih_ihi​ 表示恰好有 iii 个 a>ba>ba>b 的配对，令 gig_igi​ 为至少有 iii 个 a>ba>ba>b 的配对。ggg 是容易求出的，然后根据反演就可以求出 hhh。

这里很容易可以看出是二项式反演，然而根据二项式反演的一般套路，gig_igi​ 的准确定义其实是：固定 iii 个 a>ba>ba>b 的配对，其他随便配对的方案数。

所以 gi=fi×(n−i)!g_i=f_i\times (n-i)!gi​=fi​×(n−i)!，fif_ifi​ 为有 iii 个 a>ba>ba>b 的配对。
