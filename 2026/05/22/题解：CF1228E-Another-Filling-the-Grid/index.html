题目描述

给定一个 n×nn \times nn×n 的正方形网格和一个整数 kkk。请在每个格子中填入一个整数，要求满足以下条件：

  • 网格中所有数字都在 111 到 kkk 之间（包含 111 和 kkk）。
  • 第 iii 行的最小值为 111（1≤i≤n1 \le i \le n1≤i≤n）。
  • 第 jjj 列的最小值为 111（1≤j≤n1 \le j \le n1≤j≤n）。

请计算有多少种填数方案。由于答案可能非常大，请输出答案对 109+710^9+7109+7 取模后的结果。

题意简述

有一个 n×nn\times nn×n 的网格和一个整数 kkk，每个网格都有一个整数 ai,j∈[1,k]a_{i,j}\in[1,k]ai,j​∈[1,k]，求出满足以下条件的网格的数量：

  • 每行的最小值为 111。

  • 每列的最小值为 111。

1≤n≤2501 \le n \le 2501≤n≤250，1≤k≤1091 \le k \le 10^91≤k≤109。

做法

令行数为 nnn，列数为 mmm。

先考虑只有行条件的限制。正难则反，每一行共有 knk^nkn 种方案，有 (k−1)n(k-1)^n(k−1)n 种不合法方案（也就是所有 ai,j∈[2,k]a_{i,j}\in[2,k]ai,j​∈[2,k]）。因此每一行合法方案为 kn−(k−1)nk^n-(k-1)^nkn−(k−1)n，整个网格的合法方案为 (kn−(k−1)n)n(k^n-(k-1)^n)^n(kn−(k−1)n)n。

然后再考虑有 iii 列的限制。假如我们知道了一共有 iii 列不满足条件，并且知道是哪 iii 列。此时对于每一行，那几列的 ai,j∈[2,k]a_{i,j}\in[2,k]ai,j​∈[2,k]，因此每行总的方案数为 (k−1)ikn−i(k-1)^ik^{n-i}(k−1)ikn−i，不合法的方案数仍为 (k−1)n(k-1)^n(k−1)n，因此此时网格的合法方案数为 ((k−1)ikn−i−(k−1)n)n((k-1)^ik^{n-i}-(k-1)^n)^n((k−1)ikn−i−(k−1)n)n。

但是实际中我们只能枚举有 iii 列不满足限制，但是不能枚举是哪 iii 列，因此需要乘上一个组合数 (mi)\binom{m}{i}(im​)。

但是容易发现我们推的式子是，那 n−in-in−i 列随便放的情况，即那 n−in-in−i 列也可能存在不合法的。所以我们需要进行容斥，因此总的式子为：

ans=∑i=0m(−1)i(mi)((k−1)ikn−i−(k−1)n)nans=\sum_{i=0}^{m}(-1)^{i}\binom{m}{i}((k-1)^ik^{n-i}-(k-1)^n)^n ans=i=0∑m​(−1)i(im​)((k−1)ikn−i−(k−1)n)n
