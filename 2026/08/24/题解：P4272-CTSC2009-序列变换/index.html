题意简述

给定一个整数序列 X1,X2,X3,...,XnX_1, X_2, X_3, ... ,X_nX1​,X2​,X3​,...,Xn​ 和三个正整数 Q,A,BQ, A, BQ,A,B 满足：

  • 1≤Xi≤Q1 \leq X_i \leq Q1≤Xi​≤Q 对于任意 1≤i≤n1 \leq i \leq n1≤i≤n；

  • Xi≤Xi+1X_i \leq X_{i+1}Xi​≤Xi+1​ 对于任意 1≤i<n1 \leq i < n1≤i<n；

  • A≤Q−1n−1A \leq \frac{Q-1}{n-1}A≤n−1Q−1​ 且 A≤BA \leq BA≤B。

对于任意 1≤i≤n1 \leq i \leq n1≤i≤n，做如下变换：Yi=Xi+δiY_i = X_i + \delta_iYi​=Xi​+δi​，其中 δi\delta_iδi​ 是一个整数。使得新序列 YYY 满足如下性质：

  • 1≤Yi≤Q1 \leq Y_i \leq Q1≤Yi​≤Q 对于任意 1≤i≤n1 \leq i \leq n1≤i≤n；

  • Yi+1−Yi∈[A,B]Y_{i+1} - Y_i \in [A, B]Yi+1​−Yi​∈[A,B] 对于任意 1≤i<n1 \leq i < n1≤i<n。

对于这样一个变换，所需代价定义为 TransformCost⁡(X,Y)=∑i=1n∣δi∣\operatorname{TransformCost}(X, Y) = \sum_{i = 1}^{n}{\left\lvert\delta_i\right\rvert}TransformCost(X,Y)=∑i=1n​∣δi​∣。

本题的任务即为寻找一个变换，使得 TransformCost⁡(X,Y)\operatorname{TransformCost}(X, Y)TransformCost(X,Y) 最小化。

1≤n≤5×105,1≤Q≤109,1≤A,B≤Q1\le n \leq 5\times 10^5,1\le Q \leq 10^9, 1\leq A, B \leq Q1≤n≤5×105,1≤Q≤109,1≤A,B≤Q。

做法

简要概括一下，XiX_iXi​ 单调不减，并且 Xi∈[1,Q]X_i\in[1,Q]Xi​∈[1,Q]，第三个限制的意思实际上是一定存在合法的 YYY 序列，因此不用管。

重点显然在于 YYY 的限制，先不考虑 Yi∈[1,Q]Y_i\in [1,Q]Yi​∈[1,Q]。

令 fi,jf_{i,j}fi,j​ 为前 iii 个，Yi=jY_i=jYi​=j 的最小代价。

转移方程为：

fi,j=∣Xi−j∣+min⁡j−Bj−Afi,jf_{i,j}=\lvert X_i-j\rvert+\min_{j-B}^{j-A}f_{i,j} fi,j​=∣Xi​−j∣+j−Bminj−A​fi,j​

转移方程和 这题 非常类似，可以看 我的题解。发现是凸函数，采用 Slope trick，仅简要概括方法。

维护拐点，用两个堆维护平台左右两边，取 min⁡\minmin 操作就是将平台左端向右平移 AAA，右端向右平移 BBB，打 tagtagtag 即可。

绝对值操作分类讨论：

  • ai∈[L,R]a_i\in [L,R]ai​∈[L,R]，分别在左右两个堆加入 aia_iai​。

  • ai<La_i<Lai​<L，在左堆插入两次 aia_iai​，再把左堆顶弹入右堆。

  • ai>La_i>Lai​>L，在右堆插入两次 aia_iai​，再把右堆顶弹入左堆。

计算答案

对于 Yi∈[1,Q]Y_i\in[1,Q]Yi​∈[1,Q] 的限制，可以在计算答案时完成，先考虑 Yi≤QY_i\le QYi​≤Q。

令 aia_iai​ 为前 iii 个 Yi=aiY_i=a_iYi​=ai​ 时取到最小值，维护时取平台右端点。

从后往前考虑，因为越后面，越全局更优。如果 ai>Qa_i>Qai​>Q，直接调整 ai←Qa_i\gets Qai​←Q 即可，这样调整的代价是最小的，满足正确性。

考虑 Yi>1Y_i>1Yi​>1，本题重点在于这个。

可能存在一种情况，YiY_iYi​ 取到 aia_iai​ 后，后面无论怎样都无法满足限制 [A,B][A,B][A,B]，所以 YiY_iYi​ 实际上有一个隐藏下界，即 bi=1+(i−1)×Ab_i=1+(i-1)\times Abi​=1+(i−1)×A。

错误解法

  1. 有人可能说：和上面一样进行调整不就行了吗，如果 ai<bia_i<b_iai​<bi​，那么 ai←bia_i\gets b_iai​←bi​，但是这样是错的。

    Slope trick 有个很重要的一点：对于所有限制，都应在转移时考虑，不然求出来的最优值，是不考虑该限制的最优值，最后进行调整无法得到满足该限制的最优值。

    例如 fi−1,x,x<bi−1f_{i-1,x},x<b_{i-1}fi−1,x​,x<bi−1​ 可能转移到 fi,x+B,x+B≥bif_{i,x+B},x+B\ge b_ifi,x+B​,x+B≥bi​。

  2. 有人可能又问：满足了 Yi≤QY_i\le QYi​≤Q 的限制吗，这个还不是最后调整的，凭什么它能最后调整。

    因为 fi,Qf_{i,Q}fi,Q​ 不可能从 fi−1,x,x>Qf_{i-1,x},x>Qfi−1,x​,x>Q 的地方转移过来，所以隐式满足了这个限制。

根据上面的转移，ai<Qa_i<Qai​<Q 是容易满足的，ai>1a_i>1ai​>1 不是很好处理，所以对于 QQQ 限制，采取调整，对于 111 限制，另想它法。

正确解法 1

既然转移无法满足条件，那么使它满足条件就行。具体地，不从 <bi−1<b_{i-1}<bi−1​ 的部分转移。

则左堆需要用 set 维护，弹出首节点直到 ≥bi−1\ge b_{i-1}≥bi−1​。

但是这样会有种种不便之处，例如平台可能会被弹没，再次出现平台怎么办，tagltagltagl 应该怎么变，左堆可能为空等一堆分类讨论，稍不留神就错了，因此不推荐强硬维护。

正确解法 2

每次通过 XiX_iXi​ 更新时，都对 Xi←max⁡(Xi,bi)X_i\gets \max(X_i,b_i)Xi​←max(Xi​,bi​)，这样一定是对的，因为 XiX_iXi​ 无论如何都要到达下界，提前到达绝对是正确的。

现在看一下转移是否能自动满足条件，想了半天，终于会证了，我们只需要证合法状态的值一定由合法状态转移过来。

感性证明：因为 Xi≥biX_i\ge b_iXi​≥bi​，所以减少 XiX_iXi​ 只会使答案更劣（姑且不考虑是否可行）。全部到达下界的 XiX_iXi​ 已经是一组合法解，为了缩小代价，仅会在此基础上增加，因为实际值不会比下界小，所以不合法的 fi,jf_{i,j}fi,j​ 一定更劣，相当于已经弹出。

严谨证明

先根据凸包的转移来分类讨论，平台一定处于合法区间，即左端点 ≥Xi\ge X_i≥Xi​：

  • Xi<LX_i<LXi​<L，新平台一定在 XiX_iXi​ 右边，

  • Xi∈[L,R]X_i\in[L,R]Xi​∈[L,R]，平台就在 XiX_iXi​，合法。

  • Xi>RX_i>RXi​>R，考虑平台一共进行了那些操作，左端点先往右平移 AAA，再往右跳一次。

    因为平移前在合法区间，合法区间也是往右平移 AAA，所以平移后它就已经在合法区间内，往右跳一次更在合法区间内。

新平台一定由旧平台转移过来，我们只需关心平台以及其右部分，因为平台只会往右移，不会往左。平台已经合法，其右边肯定合法。

实际代码中就不需要将 aia_iai​ 对 bib_ibi​ 取 max⁡\maxmax 了，因为保证了平台合法。

最后再根据 [A,B][A,B][A,B] 的限制进行最小调整即可。
