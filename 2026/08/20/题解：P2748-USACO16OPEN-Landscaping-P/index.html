题解：P2748 [USACO16OPEN] Landscaping P]

题目

题目背景

本题与 2012 年 3 月月赛银组同名题目 在题意上一致，唯一的差别是数据范围。

题目描述

Farmer John 打算修建一座花园，他需要移动不少泥土。

花园由 NNN 个花坛组成（1≤N≤1051 \leq N \leq 10^51≤N≤105），其中花坛 iii 包含 AiA_iAi​ 单位的泥土。FJ 希望花坛 iii 包含 BiB_iBi​ 单位的泥土，保证 0≤Ai,Bi≤100 \leq A_i,B_i \leq 100≤Ai​,Bi​≤10。

为了达到这个目标，他可以做这几件事情：

  • 购买一单位的泥土，放在指定的花坛中，费用为 XXX。
  • 从任意一个花坛中移走一单位泥土，费用为 YYY。
  • 从花坛 iii 运送一单位泥土到花坛 jjj，费用为 Z∣i−j∣Z|i-j|Z∣i−j∣。

请你帮 FJ 计算移动泥土的最小开销。

输入格式

第一行四个整数 N,X,Y,ZN,X,Y,ZN,X,Y,Z（0≤X,Y≤1080 \leq X,Y \leq 10^80≤X,Y≤108，0≤Z≤10000 \leq Z \leq 10000≤Z≤1000）。

接下来 NNN 行，第 iii 行两个整数 Ai,BiA_i,B_iAi​,Bi​。

输出格式

输出移动泥土的最小开销。

输入输出样例 #1

输出 #1

说明/提示

按下面的方案，最小花费为 210210210，可以证明不存在开销更小的方案。

  • 移除 444 号花坛的一单位泥土，花费 200200200。
  • 将 444 号花坛的三单位泥土移到 111 号花坛，花费 3×3=93 \times 3=93×3=9。
  • 将 333 号花坛的一单位泥土移到 222 号花坛，花费 1×1=11 \times 1=11×1=1。

题意简述

花园由 nnn 个花坛组成（1≤n≤1051 \leq n \leq 10^51≤n≤105），其中花坛 iii 包含 aia_iai​ 单位的泥土。FJ 希望花坛 iii 包含 bib_ibi​ 单位的泥土，保证 0≤Ai,Bi≤100 \leq A_i,B_i \leq 100≤Ai​,Bi​≤10。

为了达到这个目标，可以做这几件事情：

  • 购买一单位的泥土，放在指定的花坛中，费用为 XXX。

  • 从任意一个花坛中移走一单位泥土，费用为 YYY。

  • 从花坛 iii 运送一单位泥土到花坛 jjj，费用为 Z∣i−j∣Z|i-j|Z∣i−j∣。

请你帮 FJ 计算移动泥土的最小开销。

0≤X,Y≤1080 \leq X,Y \leq 10^80≤X,Y≤108，0≤Z≤10000 \leq Z \leq 10000≤Z≤1000。

做法

考虑 DP

考虑 DP，令 fi,xf_{i,x}fi,x​ 为前 iii 个花坛，前 i−1i-1i−1 个花坛已经满足要求，第 iii 个花坛多了 xxx 泥土（xxx 可为负数）。

因为多的泥土肯定要往右运，则必须经过 iii，先把它们放在 iii 没有问题。少了泥土同理，贡献我们也可以提前/推迟计算。

则我们有转移方程：

fi,x=min⁡y∈R{fi−1,y+Z∣y∣+gx−y+bi−ai}f_{i,x}=\min_{y\in R}\{f_{i-1,y}+Z\lvert y\rvert+g_{x-y+b_i-a_i}\} fi,x​=y∈Rmin​{fi−1,y​+Z∣y∣+gx−y+bi​−ai​​}

其中：

gi={−iYi<0iXi≥0g_i= \begin{cases} -iY &i<0\\ \hspace{0.7em} iX &i\ge 0 \end{cases} gi​={−iYiX​i<0i≥0​

可以视为一个类绝对值函数。

yyy 我们可以大致弄一下上界，然后就可以开始算了，时间复杂度为 O(n2V)\mathcal O(n^2 V)O(n2V)，其中 VVV 为 ai,bia_i,b_iai​,bi​ 的取值范围。

惊奇地发现 ai,bia_i,b_iai​,bi​ 范围很小，为下面的算法做了铺垫。

进行优化

注意到 ggg 和 Z∣y∣Z\lvert y\rvertZ∣y∣ 都是下凸函数，然后上面转移形式很像闵可夫斯基和，考虑 Slope trick。

对于 Z∣y∣Z\lvert y\rvertZ∣y∣ 我们可以直接把它累加到 fi−1,yf_{i-1,y}fi−1,y​ 上，得到 f′f^\primef′。

对于 gx−y,bi−aig_{x-y,b_i-a_i}gx−y,bi​−ai​​，相当于有一个偏移量，根据 学习笔记，相当于把 f′f^\primef′ 或 ggg 或 hhh 偏移。

fprimef^primefprime 和 hhh 其实一样，就从这两个中选择一个进行平移。这里选择对 hhh 平移。

那么状态转移可以按顺序变成以下操作：

  • fff 的左半部分斜率 −1-1−1，右半部分 +1+1+1，得到 f′f^\primef′。

  • 将 f′,gf^\prime,gf′,g 做闵可夫斯基和，即将斜率归并，得到 hhh。

  • 将 hhh 向左平移 bi−aib_i-a_ibi​−ai​ 个单位。

考虑如何维护，先思考和 ggg 做闵可夫斯基和有什么性质。

注意到这里的 ggg 是没有上下界的，相当于有无限个为 111 的段，于是闵可夫斯基和可以转化为 f′f^\primef′ 左半部分小于 −Y-Y−Y 的斜率全部替换为 −Y-Y−Y，右半部分大于 XXX 的斜率全部替换为 XXX。

因为 ggg 可以把其余的无限往两遍挤压，相当于删除掉。

这里有一个非常优秀的细节，就是 ggg 的左半部分和 Z∣y∣Z\lvert y\rvertZ∣y∣ 的左半部分是一样的，都是以 000 为分界点，这大大方便了我们处理，这就是我们不选择 ggg 平移的原因。

维护

这里的斜率变化非常大，所以要维护斜率。

经过刚才的分析，分界点都是 000，所以可以用两个数据结构分别维护左右两边。

同时 X,YX,YX,Y 都是全局的，所以可以在弹出的时候直接对 X,YX,YX,Y 取 min⁡\minmin 或 max⁡\maxmax，没必要真正弹出，替换。

绝对值的操作直接打 tagtagtag 就行。

平移操作就把 bi−aib_i-a_ibi​−ai​ 个元素向左/右平移。

发现数据结构只需要维护平移操作，即弹出，加入，直接用两个开口向原点的栈即可。

这里可能会存疑：

  • 栈中的每个元素都是长度为 111 的斜率吗，不可能一个数代表长度为 kkk 的斜率段吗？

为了解决这个问题，我们先考虑如果弹出时，一边栈为空怎么办？

我们的实际斜率是绝对不可能为空的，因为一定有无限个斜率为 X,−YX,-YX,−Y 的段。因此栈为空时，直接弹出 −Y-Y−Y 或 XXX。

初始状态下，我们两个栈都是空的，这样弹出每次都弹 111个单位，所以上面问题得以解决。
