题解：P12074 [OOI 2025] The arithmetic exercise

题目描述

Oleg 和 Dasha 参加了一场团队竞赛，但不幸的是，他们未能解决任何问题。Oleg 立刻意识到他们的队伍训练不足。然后，他们共同的朋友提出了一个有趣的练习。这个练习相当简单，要解决它，只需要知道整数加减法的规则。

给定一个长度为 nnn 的数组 aaa，初始时所有值均为零。同时给定 mmm 个数 x1,x2,…,xmx_1, x_2, \ldots, x_mx1​,x2​,…,xm​。然后，对于从 111 到 mmm 的每个 iii，你需要选择某个下标 jij_iji​，并执行更改 aji=xi−ajia_{j_i} = x_i - a_{j_i}aji​​=xi​−aji​​。

请帮助 Oleg 和 Dasha 确定，如果每次选择都最优，那么在所有更改完成之后，数组 aaa 的元素之和的最大值可能为多少。

输入格式

每个测试包含多个输入数据集。第一行包含一个整数 ttt（1≤t≤10 0001 \le t \le 10\,0001≤t≤10000）—— 输入数据集的数量。

每个数据集的第一行包含两个整数 nnn 和 mmm。（1≤n,m≤300 0001 \le n, m \le 300\,0001≤n,m≤300000）

每个数据集的第二行包含 mmm 个整数 x1,x2,…,xmx_1, x_2, \ldots, x_mx1​,x2​,…,xm​。（−109≤xi≤109-10^9 \le x_i \le 10^9−109≤xi​≤109）

设 NNN 为所有数据集中 nnn 的总和，MMM 为所有数据集中 mmm 的总和。

保证 NNN 和 MMM 均不超过 300 000300\,000300000。

输出格式

对于每个数据集，在新的一行输出一个数字 —— 可以得到的数组 aaa 的和的最大值。

样例解释

在第一个数据集中，所有操作都应用于数组 aaa 的第一个元素。它依次变为 1−0=11 - 0 = 11−0=1，2−1=12 - 1 = 12−1=1，3−1=23 - 1 = 23−1=2，4−2=24 - 2 = 24−2=2，所以答案是 222。

在第二个数据集中，可以执行以下更改序列：

  1. 将更改应用于第一个元素：a1=10−a1=10−0=10a_1 = 10 - a_1 = 10 - 0 = 10a1​=10−a1​=10−0=10，此时 a=[10,0]a = [10, 0]a=[10,0]。
  2. 将更改应用于第一个元素：a1=3−a1=3−10=−7a_1 = 3 - a_1 = 3 - 10 = -7a1​=3−a1​=3−10=−7，此时 a=[−7,0]a = [-7, 0]a=[−7,0]。
  3. 将更改应用于第一个元素：a1=7−a1=7−(−7)=14a_1 = 7 - a_1 = 7 - (-7) = 14a1​=7−a1​=7−(−7)=14，此时 a=[14,0]a = [14, 0]a=[14,0]。
  4. 将更改应用于第一个元素：a1=1−a1=1−14=−13a_1 = 1 - a_1 = 1 - 14 = -13a1​=1−a1​=1−14=−13，此时 a=[−13,0]a = [-13, 0]a=[−13,0]。
  5. 将更改应用于第二个元素：a2=4−a2=4−0=4a_2 = 4 - a_2 = 4 - 0 = 4a2​=4−a2​=4−0=4，此时 a=[−13,4]a = [-13, 4]a=[−13,4]。
  6. 将更改应用于第一个元素：a1=6−a1=6−(−13)=19a_1 = 6 - a_1 = 6 - (-13) = 19a1​=6−a1​=6−(−13)=19，此时 a=[19,4]a = [19, 4]a=[19,4]。
  7. 将更改应用于第二个元素：a2=3−a2=3−4=−1a_2 = 3 - a_2 = 3 - 4 = -1a2​=3−a2​=3−4=−1，此时 a=[19,−1]a = [19, -1]a=[19,−1]。

最后，我们得到 a=[19,−1]a = [19, -1]a=[19,−1]，所以最终的和是 181818。

可以证明不可能得到更好的结果。

题意简述

给定一个长度为 nnn 的数组 aaa，初始时所有值均为零。同时给定 mmm 个数 x1,x2,…,xmx_1, x_2, \ldots, x_mx1​,x2​,…,xm​。然后，对于从 111 到 mmm 的每个 iii，你需要选择某个下标 jij_iji​，并执行更改 aji=xi−ajia_{j_i} = x_i - a_{j_i}aji​​=xi​−aji​​。

1≤n,m≤3×1051\le n,m\le 3\times 10^51≤n,m≤3×105，−109≤xi≤109-10^9\le x_i\le 10^9−109≤xi​≤109。

做法

注意到每个 xix_ixi​ 的贡献是要么是 −xi-x_i−xi​，要么是 xix_ixi​，而之前放的数可能会被后面的数影响而翻转符号，故从后往前考虑。

容易发现正号的数一定不小于负号的，故令 fi,jf_{i,j}fi,j​ 为后 iii 个数，正号减负号的数的个数为 jjj。

转移方程为：

fi,j=max⁡{fi−1,j−1+xi,fi−1,j+1−xi}f_{i,j}=\max\{f_{i-1,j-1}+x_i,f_{i-1,j+1}-x_i\} fi,j​=max{fi−1,j−1​+xi​,fi−1,j+1​−xi​}

这个很像 Slope trick 的形式，但是缺了一项：fi−1,j+0f_{i-1,j}+0fi−1,j​+0，无法直接做闵可夫斯基和。

考虑进一步化简式子，两遍都有 xix_ixi​ 不好处理，可以变为：

fi,j=max⁡{fi−1,j−1+2xi,fi−1,j+1}−xif_{i,j}=\max\{f_{i-1,j-1}+2x_i,f_{i-1,j+1}\}-x_i fi,j​=max{fi−1,j−1​+2xi​,fi−1,j+1​}−xi​

下文把 −xi-x_i−xi​ 省去。

挖掘性质

这里有一个非常奇妙的性质，j−1j-1j−1 与 j+1j+1j+1 的奇偶性相同，意味着可以按小标奇偶性把 fif_ifi​ 的函数图像分为两部分。

其中奇下标转移到偶下标，偶下标转移到奇下标。

那么我们对于 j−1j-1j−1 和 j+1j+1j+1，就可以把它们视为相邻的，具体地，可以把 2j2j2j，2j+12j+12j+1 视为一体。

所以转移方程变为这样，对于奇下标：

fi,j=max⁡{fi−1,j+2xi,fi−1,j+1}f_{i,j}=\max\{f_{i-1,j}+2x_i,f_{i-1,j+1}\} fi,j​=max{fi−1,j​+2xi​,fi−1,j+1​}

对于偶下标：

fi,j=max⁡{fi−1,j−1+2xi,fi−1,j}f_{i,j}=\max\{f_{i-1,j-1}+2x_i,f_{i-1,j}\} fi,j​=max{fi−1,j−1​+2xi​,fi−1,j​}

奇下标的转移就变成了对 hjh_jhj​ 做闵可夫斯基和：

hj={0j=−12xij=0h_j= \begin{cases} 0 &j=-1\\ 2x_i &j=0 \end{cases} hj​={02xi​​j=−1j=0​

偶下标则是对：

hj={0j=02xij=1h_j= \begin{cases} 0 &j=0\\ 2x_i &j=1 \end{cases} hj​={02xi​​j=0j=1​

两种情况的 hjh_jhj​ 斜率都为 2xi2x_i2xi​。

故 fif_ifi​ 为凸函数，且闵可夫斯基和的结果是斜率归并，此题肯定是用堆维护每个长度为 111 的斜率段，因此在堆中插入 2xi2x_i2xi​ 即可。

细节

我们不需要维护两个凸函数，因为只有 i,ji,ji,j 奇偶性相同的时候才有意义。i→i+1i\to i+1i→i+1 后，jjj 的奇偶性一定会发生变化（可以由分类讨论得出），初始状态是 f1,1f_{1,1}f1,1​，因此结论可证。

在 nnn 个格子中，jjj 是有上界 upupup 的，分类讨论一下：

  1. nnn 为奇数。

    • iii 为奇数，up=⌈n2⌉=n+12up=\left\lceil \frac{n}{2}\right\rceil=\frac{n+1}{2}up=⌈2n​⌉=2n+1​。

    • iii 为偶数，up=⌊n2⌋+1=⌊n+22⌋up=\left\lfloor \frac{n}{2}\right\rfloor+1=\left\lfloor \frac{n+2}{2}\right\rfloorup=⌊2n​⌋+1=⌊2n+2​⌋。

  2. nnn 为偶数

    • iii 为奇数，up=n2=⌊n+12⌋up=\frac{n}{2}=\left\lfloor \frac{n+1}{2}\right\rfloorup=2n​=⌊2n+1​⌋。

    • iii 为偶数，up=n2+1=n+22up=\frac{n}{2}+1=\frac{n+2}{2}up=2n​+1=2n+2​。

式子稍微模拟一下不难得出。nnn 的两种情况在代码里都一样的。

n/2n/2n/2 是因为把 2j2j2j，2j+12j+12j+1 视为了整体，iii 为偶数时 +1+1+1 是因为 jjj 可以 =0=0=0。

在元素个数 ≥up\ge up≥up 时，需要不断弹出后面的斜率，注意 upupup 是状态数，斜率段的个数是 up−1up-1up−1。

考虑通过左端点求，这里需要清楚 iii 为奇/偶数时，凸函数的具体变化。

我们以斜率为 2xi2x_i2xi​ 为平台。

  • iii 为奇数时，平台左边取 fi−1,j+1f_{i-1,j+1}fi−1,j+1​ 更优，整体向左平移一个单位，平台右边取 fi−1,j+2xif_{i-1,j}+2x_ifi−1,j​+2xi​ 更优，整体向上平移 2xi2x_i2xi​，平台也整体向上平移，所以实际上斜率为 2xi2x_i2xi​ 的段是这样拉出来的。

    然而向左平移后会有一段斜率到第二象限去，所以要弹出，同时这一段抬高了左端点的高度，所以答案要加上它。通过图片直观感受。

    在此图中，平台为 2xi=12x_i=12xi​=1，新增的斜率为 2xi2x_i2xi​ 的段就是 CDCDCD，左端点由 0→40\to 40→4。

  • iii 为偶数时，平台左边取 fi−1,jf_{i-1,j}fi−1,j​ 更优，整体不动，右边取 fi−1,j−1+2xif_{i-1,j-1}+2x_ifi−1,j−1​+2xi​ 更优，整体向右移动 111 单位，向上移动 2xi2x_i2xi​，平台也不动，所以这种情况的斜率段是右边拉出来的，左边不会不合法，因此不用管。

    平台还是 2xi=12x_i=12xi​=1，新增的斜率段为 CGCGCG。

所以用堆还不够，不仅要弹出后面的斜率，还要弹出前面的，因此要用 multiset。

答案就是左端点加上所有正斜率。别忘了开头省略掉的 −∑i=1nxi-\sum_{i=1}^n x_i−∑i=1n​xi​。
