题解：P3265 [JLOI2015] 装备购买

前言

此题并不是异或线性基，而是最本真的线性基，下文详细解说。

题目传送门。

▶
题目

题目描述

脸哥最近在玩一款神奇的游戏，这个游戏里有 nnn 件装备，每件装备有 mmm 个属性，用向量 zi=(a1,…,aj,…,am)\mathbf{z_i}=(a_1, \ldots ,a_j, \ldots , a_m)zi​=(a1​,…,aj​,…,am​) 表示 (1≤i≤n, 1≤j≤m1 \leq i \leq n, \ 1 \leq j \leq m1≤i≤n, 1≤j≤m)，每个装备需要花费 cic_ici​，现在脸哥想买一些装备，但是脸哥很穷，所以总是盘算着怎样才能花尽量少的钱买尽量多的装备。对于脸哥来说，如果一件装备的属性能用购买的其他装备组合出（也就是说脸哥可以利用手上的这些装备组合出这件装备的效果），那么这件装备就没有买的必要了。

严格的定义是，如果脸哥买了 zi1,…,zip\mathbf{z_{i_1}}, \ldots , \mathbf{z_{i_p}}zi1​​,…,zip​​这 ppp 件装备，那么对于任意待决定的 zh\mathbf{z_h}zh​，不存在 b1,…,bpb_1, \ldots ,b_pb1​,…,bp​使得 b1zi1+…+bpzip=zhb_1\mathbf{z_{i_1}} + \ldots + b_p\mathbf{z_{i_p}} = \mathbf{z_h}b1​zi1​​+…+bp​zip​​=zh​
​​ （bib_ibi​均是实数），那么脸哥就会买 zh\mathbf{z_h}zh​，否则 zh\mathbf{z_h}zh​ 对脸哥就是无用的了，自然不必购买。

举个例子，z1=(1,2,3), z2=(3,4,5), zh=(2,3,4), b1=12, b2=12\mathbf{z_1}=(1, 2, 3), \ \mathbf{z_2}=(3, 4, 5), \ \mathbf{z_h}=(2, 3, 4), \ b_1 =\frac{1}{2}, \ b_2 =\frac{1}{2}z1​=(1,2,3), z2​=(3,4,5), zh​=(2,3,4), b1​=21​, b2​=21​，就有 b1z1+b2z2=zhb_1\mathbf{z_1} + b_2\mathbf{z_2} = \mathbf{z_h}b1​z1​+b2​z2​=zh​ ，那么如果脸哥买了 z1\mathbf{z_1}z1​和 z2\mathbf{z_2}z2​ 就不会再买 zh\mathbf{z_h}zh​了。

脸哥想要在买下最多数量的装备的情况下花最少的钱，你能帮他算一下吗？

输入格式

第一行两个数 n,mn,mn,m。接下来 nnn 行，每行 mmm 个数，其中第 iii 行描述装备 iii 的各项属性值。接下来一行 nnn 个数，其中 cic_ici​ 表示购买第 iii 件装备的花费。

输出格式

一行两个数，第一个数表示能够购买的最多装备数量，第二个数表示在购买最多数量的装备的情况下的最小花费。

输入输出样例 #1

输入 #1

输出 #1

说明/提示

如题目中描述，选择装备 111 装备 222，装备 111 装备 333，装备 222 装备 333 均可，但选择装备 111 和装备 222 的花费最小，为 222。

对于 100%100\%100% 的数据 ,1≤n,m≤500,1 \le n,m \le 500,1≤n,m≤500，0≤aj≤10000 \le a_j \le 10000≤aj​≤1000。

题意简述

有 nnn 个 mmm 维向量，每个向量都有一个代价 wiw_iwi​，如果向量 a=λb+μc+…\mathbf a=\lambda\mathbf b+\mu\mathbf c+\dotsa=λb+μc+…，那么 a\mathbf aa 可以不购买；如果不能被别的表示，那么必须购买。

求满足上述条件，最小需要多少代价购买。

1≤n,m≤5001 \le n,m \le 5001≤n,m≤500，0≤wj≤10000 \le w_j \le 10000≤wj​≤1000。

做法

考虑 a=λb+μc\mathbf a=\lambda\mathbf b+\mu\mathbf ca=λb+μc，可以写成 γa+λb+μc=0\gamma\mathbf a+\lambda\mathbf b+\mu\mathbf c=\mathbf 0γa+λb+μc=0。

也就是说 a,b,c\mathbf a,\mathbf b,\mathbf ca,b,c 都可以被另外两个表示，我们不妨贪心选择代价小的两个，代价最大的被它们表示。

因此我们先将其按代价从小到大排序。

线性基也满足上面的性质，内部的元素无法相互操作变成 000。

线性基本质上就是一个向量，因为每个数都可以拆分成 log⁡V\log VlogV 个 01\texttt{01}01 串，相当于 log⁡V\log VlogV 维向量，插入每个数进行的实际上是高斯消元操作，因为 1⊕1=01\oplus 1=01⊕1=0，我们每次就是要消去高位的 000。

在本题中，我们维护 mmm 个向量，用 pip_ipi​ 表示，考虑插入元素 a\mathbf aa，不断消去高位，如果 pjp_jpj​ 为空，则把 pjp_jpj​ 赋值成当前的 a\mathbf aa，答案加上代价。

时间复杂度为 O(nlog⁡n+nm2)\mathcal O(n\log n+nm^2)O(nlogn+nm2)。

为了防止爆精度，我们可以在模意义下进行，不影响时间复杂度。
