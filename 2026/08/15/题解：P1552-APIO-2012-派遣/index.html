题解：P1552 [APIO 2012] 派遣

前言

带简单贪心的可并堆。

题目传送门。

▶
题目

题目背景

在一个忍者的帮派里，一些忍者们被选中派遣给顾客，然后依据自己的工作获取报偿。

题目描述

在这个帮派里，有一名忍者被称之为 Master。除了 Master 以外，每名忍者都有且仅有一个上级。为保密，同时增强忍者们的领导力，所有与他们工作相关的指令总是由上级发送给他的直接下属，而不允许通过其他的方式发送。

现在你要招募一批忍者，并把它们派遣给顾客。你需要为每个被派遣的忍者支付一定的薪水，同时使得支付的薪水总额不超过你的预算。另外，为了发送指令，你需要选择一名忍者作为管理者，要求这个管理者可以向所有被派遣的忍者发送指令，在发送指令时，任何忍者（不管是否被派遣）都可以作为消息的传递人。管理者自己可以被派遣，也可以不被派遣。当然，如果管理者没有被派遣，你就不需要支付管理者的薪水。

你的目标是在预算内使顾客的满意度最大。这里定义顾客的满意度为派遣的忍者总数乘以管理者的领导力水平，其中每个忍者的领导力水平也是一定的。

写一个程序，给定每一个忍者 iii 的上级 BiB_iBi​，薪水 CiC_iCi​，领导力 LiL_iLi​，以及支付给忍者们的薪水总预算 MMM，输出在预算内满足上述要求时顾客满意度的最大值。

输入格式

第一行包含两个整数 NNN 和 MMM，其中 NNN 表示忍者的个数，MMM 表示薪水的总预算。

接下来 NNN 行描述忍者们的上级、薪水以及领导力。其中的第 iii 行包含三个整数 Bi,Ci,LiB_i,C_i,L_iBi​,Ci​,Li​ 分别表示第 iii 个忍者的上级，薪水以及领导力。Master 满足 Bi=0B_i=0Bi​=0，并且每一个忍者的老板的编号一定小于自己的编号 Bi<iB_i\lt iBi​<i。

输出格式

一行一个整数，表示在预算内顾客的满意度的最大值。

输入输出样例 #1

输入 #1

输出 #1

说明/提示

1≤N≤1051 \le N \le 10^51≤N≤105，1≤M≤1091 \le M \le 10^91≤M≤109，0≤Bi<i0 \le B_i \lt i0≤Bi​<i，1≤Ci≤M1 \le C_i \le M1≤Ci​≤M，1≤Li≤1091 \le L_i \le 10^91≤Li​≤109。

对于 30%30\%30% 的数据，N≤3000N \le 3000N≤3000。

题意简述

一棵 nnn 个节点的树，每个节点都有 222 个参数：Ci,LiC_i,L_iCi​,Li​，还有一个限制 mmm。

可以选择任意节点 xxx，然后选择其子树的任意个节点，要求选择的节点（包括 xxx）的 CiC_iCi​ 总和不超过 mmm。令一共选了 kkk 个节点，那么这样的价值为 k×Lik\times L_ik×Li​，求出最大的 k×Lik\times L_ik×Li​。

做法

先考虑一个节点 xxx，如何最大化它的 k×Lik\times L_ik×Li​，显然不断减去它子树内 CiC_iCi​ 最大的，直到满足 mmm 的限制。

于是我们可以维护一个堆，不断 pop⁡\operatorname{pop}pop 直到满足条件。

如何维护所有节点呢？xxx 不要的，faxfa_xfax​ 肯定也不要，这是显然的，所以我们弹出后的可以不用管。因此我们可以把 xxx 子节点的堆合并起来，然后再 pop⁡\operatorname{pop}pop。

直接上可并堆（左偏树）即可。
