题目

题目描述

Alice 和 Bob 在玩一个游戏。

游戏在一棵有 nnn 个点的树上进行。最初，每个点上都只有一个数字，那个数字是 123456789123456789123456789123456789123456789123456789。

有时，Alice 会选择一条从 sss 到 ttt 的路径，在这条路径上的每一个点上都添加一个数字。对于路径上的一个点 rrr，若 rrr 与 sss 的距离是 disdisdis，那么 Alice 在点 rrr 上添加的数字是 a×dis+ba\times dis+ba×dis+b。

有时，Bob 会选择一条从 sss 到 ttt 的路径。他需要先从这条路径上选择一个点，再从那个点上选择一个数字。

Bob 选择的数字越小越好，但大量的数字让 Bob 眼花缭乱。Bob 需要你帮他找出他能够选择的最小的数字。

输入格式

第一行两个数字 n,mn,mn,m，表示树的点数和进行的操作数。

接下来 n−1n-1n−1 行，每行三个数字 u,v,wu,v,wu,v,w，表示树上有一条连接 u,vu,vu,v 的边，长度是 www。

接下来 mmm 行。每行第一个数字是 111 或 222。

若第一个数是 111，表示 Alice 进行操作，接下来四个数字 s,t,a,bs,t,a,bs,t,a,b。

若第一个数是 222，表示 Bob 进行操作，接下来两个数字 s,ts,ts,t。

输出格式

每当 Bob 进行操作，输出一行一个数，表示他能够选择的最小的数字

题意简述

有一棵 nnn 个点的树，每条边都有边权 wiw_iwi​，每个点初始时上都只有一个数字： 123456789123456789123456789123456789123456789123456789。

有 mmm 次操作，分为两种：

  • opt  s  t  a  bopt\;s\;t\;a\;boptstab：在 sss 到 ttt 的路径上，每一个点都添加一个数字。对于路径上的点 rrr，若 rrr 与 sss 的距离是 disdisdis（路径上的边权和），那么在点 rrr 上添加的数字是 a×dis+ba\times dis+ba×dis+b。

  • opt  s  topt\;s\;toptst：在 sss 到 ttt 的路径上先选择一个点，再从那个点上选择一个数字。求出能选出的最小数字。

1≤n,m≤1051\le n,m\le 10^51≤n,m≤105，∣a∣≤104\lvert a\rvert\le 10^4∣a∣≤104，0≤w,∣b∣≤1090\le w,\lvert b\rvert\le 10^90≤w,∣b∣≤109。

做法

容易发现 a×dis+ba\times dis+ba×dis+b 是一个一次函数的形式，不难想到用李超线段树维护。

同时我们可以用树链剖分将其拆成一个个序列，在李超线段树的下标为 dfnidfn_idfni​，每个点到根节点的距离为 did_idi​。

令 lca=LCA⁡(s,t)lca=\operatorname{LCA}(s,t)lca=LCA(s,t)，我们可以将其分成两段：

  • s−lcas-lcas−lca，在 lcalcalca 到 sss 上，dfn,disdfn,disdfn,dis 单调递增，但是离 sss 越近，disdisdis 越小，所以我们需要将斜率变为 −a-a−a，bbb 就变为 b+a×dsb+a\times d_sb+a×ds​。

  • t−lcat-lcat−lca，跟上面同样分析，斜率还是 aaa，令 DisDisDis 为 s−lcas-lcas−lca 的路径长度，bbb 变为 b+a×Dis−a×dlcab+a\times Dis-a\times d_{lca}b+a×Dis−a×dlca​。

树链剖分的时间复杂度为 log⁡n\log nlogn，李超线段树是插入线段，所以是 log⁡2n\log^2 nlog2n。

查询是李超树区间查询，需要对每个节点维护一个 minnminnminn，表示该区间的最小值。

对于一条直线，容易知道最小值一定取在端点，写个 push_up 就行。

但是查询区间可能与线段是相交而不是包含关系，因此遍历到每个节点时，都计算一下左右端点并取 min⁡\minmin 就行，详情见代码。

查询时间复杂度就是 222 个 log⁡\loglog。

所以总的时间复杂度为 O(nlog⁡3n)\mathcal O(n\log ^3n)O(nlog3n)。

这样写代码细节比较多，因为涉及区间与区间中的关系。

可以对每个重链维护一个李超线段树，动态开点，这样时间/空间复杂度相同，常数、细节会减小很多。
