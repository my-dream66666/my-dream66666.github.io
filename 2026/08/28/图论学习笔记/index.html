Johnson 全源最短路

题目传送门，几乎不记得了，写一下算法流程吧。费用流的原始对偶算法需要用。

Johnson 全源最短路用来处理存在负权边的有向图，需要求出任意两点之间的距离。

Floyed 算法可以做到 O(n3)\mathcal O(n^3)O(n3)，但是在稀疏图中不够优秀。

我们也不能直接用 Dijkstra 算法，因为存在负权，不满足贪心。考虑将所有边变成正权。

如果把所有边加上一个值，最短路后再减去，这样显然是错的。

建一个虚拟节点 000，向所有点连一条权值为 000 的边，用 Bellman-Ford 算法求出它到所有点的最短路 disidis_idisi​。

那么，对于边 u→vu\to vu→v，边权变为 wu,v+disu−disvw_{u,v}+dis_u-dis_vwu,v​+disu​−disv​，这时边权变为正数，然后对每个点分别跑 Dijkstra 算法即可，得出的最短路就是最短路，不用进行别的操作。
因为最短路有著名的三角不等式 disv−disu≤widis_v-dis_u\le w_idisv​−disu​≤wi​，则 disu−disv+wi≥0dis_u-dis_v+w_i\ge 0disu​−disv​+wi​≥0，得证。

之后对于 SSS 到任意一个点 xxx 的最短路，变为了 disS−disx+d(S,x)dis_S-dis_x+d(S,x)disS​−disx​+d(S,x)，d(u,v)d(u,v)d(u,v) 为 u,vu,vu,v 在原图上的最短路。又因为 disS=0dis_S=0disS​=0，所以变为了 d(S,x)−disxd(S,x)-dis_xd(S,x)−disx​。

发现这个值之和原图的边权以及终点 xxx 的 disxdis_xdisx​ 有关，因此不会影响贪心的正确性，这样就可以做 Dijkstra 算法了。

连通分量

与连通块不同，常用的有有向图强连通分量，无向图点双连通分量、边双连通分量。令一个连通分量的集合为 SSS，我们讨论的默认为极大联通分量。

在处理连通分量时，我们采用的都是 tarjan 算法。一般用其来缩点（将一个连通分量缩成一个点），可以得到一个森林或者 DAG（有向无环图）。

有向图强连通分量

题目传送门，对于一个强连通分量，任意一个点都可以通过 SSS 的某些点到达 SSS 的所有点。（一个点也属于一个强连通分量）

在有向图中，最简单的强连通分量就是一个环，在环的基础上，其他点也可以任意连边。更复杂的，两个环可以通过一个点或者一条边套在一起，形成一个更大的强连通分量。

在 SSS 中，有且仅有一个最先遍历的点 xxx，SSS 的其他点 uuu 的 lowulow_ulowu​ 都等于 dfnxdfn_xdfnx​。

无向图连通分量

分为点双连通分量和边双连通分量。

点双连通分量

最小生成树

浅浅说一下每个算法的流程。

Prim 算法

任意选出一个点 xxx 作为初始顶点,加入到 MST 中,并计算所有与 xxx 相连接的点的距离 disidis_idisi​。（初始化）

重复以下操作，直到所有点都被加入到 MST 中：从 MST 中的点出发，在没有加入到 MST 的点中选择与之距离最短的点 kkk，并将 kkk 点加入到MST中。然后用 kkk 来更新别的点的距离。

这个算法酷似 Dijkstra 算法，时间复杂度为 O((n+m)log⁡n)\mathcal O((n+m)\log n)O((n+m)logn)，一般不写成 log⁡m\log mlogm，因为量级相等，而且 mmm 只是瞬时最劣情况，用 log⁡n\log nlogn 差不多抵消。

Kruska 算法

最常用的算法。将边排序，依次加入，用并查集判断两个点是否联通，如果不连通，那么这条边属于 MST，合并一下并计入答案。

时间复杂度瓶颈在排序，时间复杂度为 O(mlog⁡m)\mathcal O(m\log m)O(mlogm)，时间复杂度是三个算法中最高的，但是常数小，好写。

▶
code

Boruvka 算法

最古老的算法，可以看作上面了两个方法的综合。

先将每个点视为一个连通块，然后找出每个联通块到其他连通块的最小边，将其合并并计入答案。

因为是尝试合并每个连通块，所以每次联通块的个数都会减少一半，因此进行 log⁡n\log nlogn 轮，每轮 O(m)\mathcal O(m)O(m)，因此时间复杂度为 O((n+m)log⁡n)\mathcal O((n+m)\log n)O((n+m)logn)。

这个按理来说时间复杂度是最低的，因为这个 log⁡n\log nlogn 比 Prim 是严格的。

有些题很适合用 Boruvka，因此需要知道它的流程。

Kruska 重构树

经典算法。可以把图变成一棵树。弄了个 题单。

在 Kruska 合并两个联通块时，新建一个节点，称为新联通块的根，将两个联通块的根指向这个新节点，并且把边的边权变成这个新节点的点权。

容易发现这样会建成一棵二叉树，并且原图的每个节点都是叶子节点，原图两个点之间的路径，就是重构树路径上非叶子节点的点权集合，并且每个新建节点的权值形成了一个堆，堆顶元素最大/小。

考虑建出 Kruska 最小重构树，查询即查询两个点的 LCA。

仙人掌

讲了圆方树，肯定要有仙人掌。

无向仙人掌图的定义是：任意一条边至多只出现在一条简单回路的无向连通图称为仙人掌。简单来说就是不存在公共边。

考察仙人掌图的结构：

蓝色的为割点，红色的为割边，在仙人掌上，也称割边为桥。这两个做题时需要重点考虑的对象。而且仙人掌上的一个点双连通分量（第二种定义），必定是一个环。

先放 板子：

给一个仙人掌图，qqq 次询问，求出两个点之间的最短距离。

考虑将仙人掌转化成圆方树（过程不再多说），考虑圆点到方点的边权是什么。

发现在圆方树中，对于一个点双连通分量，割点是其根节点，如果路径需要跨过这个点双连通分量，那么在圆方树上，必然要经过这个割点。

因此这样定义边权，每个圆点到方点的距离，为它到割点距离的最小值。

考虑查询 x,yx,yx,y，肯定要求出 LCA，对其分类讨论：

  • LCA 为圆点，直接求出路径和即可。

  • LCA 为方点，即路径没有跨过这个点双连通分量。令 s,ts,ts,t 分别为 x,yx,yx,y 的祖先节点，且为方点的子节点，那么 x−s,y−tx-s,y-tx−s,y−t 的路径是必须的。剩下的就是 s,ts,ts,t 距离的最小值，即求环上任意两点最小值，下文会说。

问题在于如何求出方点到圆点的距离，我们提取出每个点双连通分量（环），先顺时针求出它到割点的距离（前缀和），然后可以算出逆时针的距离，取最小值即可。

还要求出环上任意两点的距离，直接前缀和相减即可。

广义串并联图

图论最难的一档，~~虽然我觉得是水黑。~~起源于吴作同老师在 201920192019 年的集训队论文《公园》命题报告。

定义广义串并联图是一类不存在同胚于 K4K_4K4​ 的子图的无向连通图。其中 K4K_4K4​ 为四个点的完全图。我们通过这个挖掘一些性质。

对于同胚，是指原图插入或删除二度点（也称细分和平滑）生成的新图，具体如下：

  • 细分：对于边 u−vu-vu−v，在中间插入一个点 www，得到 u−w−vu-w-vu−w−v。

  • 平滑：细分的逆操作，对于边 u−w−vu-w-vu−w−v，删除 www 得到 u−vu-vu−v。

对于 K5K_5K5​ 之类的，它们包含 K4K_4K4​，故可以用 K4K_4K4​ 代表它们。即用低维度的代表高维度的，低维度都不满足，高维度肯定也不满足。

证明

证明不是很严谨，不过感性理解一下显然可知。

首先，对于一个 K4K_4K4​，删除它的任意两个点，剩下的点仍然可以联通，我们需要证明串联和并联操作不会引入同胚于 K4K_4K4​ 的子图。

还要说明一点，合并前两图均没有同胚于 K4K_4K4​ 的子图，合并后如果存在，则那个 K4K_4K4​ 一定包含合并的点。假如我们分别选了在 G1,G2G_1,G_2G1​,G2​ 选了两个点 x,yx,yx,y 和 a,ba,ba,b，它们都不是合并点，x,yx,yx,y 与 a,ba,ba,b 之间没有直接相连的边，它们本来就不连通。

对于串联操作，合并的那个节点显然是割点，删去它后就已经不连通，得证。

对于并联操作，删除两个合并的点后，G1G_1G1​ 和 G2G_2G2​ 已经不连通，得证。

对于一个广义串并联图，可以通过以下操作形成一个单点：

  • 删 111 度点。对于点 uuu，若 degu=0deg_u=0degu​=0，删除 uuu 以及与 uuu 相连的唯一边 u−vu-vu−v，相当于把 uuu 缩到 vvv 上。

  • 缩 222 度点。对于边 u−w−vu-w-vu−w−v，把 www 删除，类似于上面的平滑操作，相当于把 www 缩到边 u−vu-vu−v 上。

  • 叠合重边。若 u−vu-vu−v 之间有两条边，把它们叠成一条。相当于把一条边缩到另一条上。

以上操作称为广义串并联图方法。

容易发现一个 K4K_4K4​ 不能通过上面的操作缩成单点，而 K4K_4K4​ 删除了一条边的图可以。因为广义串并联图不存在同胚于 K4K_4K4​ 的子图，故它一定会缩成一个单点。

如上面所说，每个操作相当于是把一个点/边的信息，合并到令一个点/边上，这样可以做一些计数之类的题。

性质和应用

对于一些题目，我们可以强化命题。例如树和仙人掌显然是广义串并联图，而广义串并联图不一定是树或仙人掌。我们在做题时可以把它们视为广义串并联图。

广义串并联图有一个很重要的性质：**在压缩的过程中，一个点/边代表一个子图。**我们需要根据这个来考虑 DP。

例题：

给定无向连通图 GGG，已知 GGG 在删掉一条边后是一颗仙人掌，求 GGG 的生成树个数。结果对 998244353998244353998244353 取模。1≤n≤m≤2×1051 \le n \le m \le2 \times 10^51≤n≤m≤2×105。

仙人掌加一条边后，仍然是广义串并联图。考虑最接近 K4K_4K4​ 的情况，若仙人掌存在一个 444 元环，在其中加一条边后，仍然差一条边才形成一个 K4K_4K4​，故得证。

因为每条边代表一个子图，所以令 fu,vf_{u,v}fu,v​ 为边 u−vu-vu−v 代表的子图中，u,vu,vu,v 相连的生成树方案数，gu,vg_{u,v}gu,v​ 是 u,vu,vu,v 不相连的生成树森林方案数。

值得注意的是，gu,vg_{u,v}gu,v​ 只能指形成两个不相连生成树的方案数，这是我们转移需要的，不然会多出独立的连通块。

分别对三个操作考虑如何转移：

  • 删 111 度点。将这条边的 fff 乘进答案。

  • 缩 222 度点。fe←fe1fe2f_e\gets f_{e_1}f_{e_2}fe​←fe1​​fe2​​，ge←fe1ge2+ge1fe2g_e\gets f_{e_1}g_{e_2}+g_{e_1}f_{e_2}ge​←fe1​​ge2​​+ge1​​fe2​​。

  • 叠合重边。两条边不能同时在生成树上，fe←fe1ge2+ge1fe2f_e\gets f_{e_1}g_{e_2}+g_{e_1}f_{e_2}fe​←fe1​​ge2​​+ge1​​fe2​​，ge←ge1ge2g_e\gets g_{e_1}g_{e_2}ge​←ge1​​ge2​​。

很多题目都是在删 111 度点的时候计算答案。

在代码的过程中，使用 map 来存边的信息，因为要支持删边，vector 时间复杂度爆炸。而且一般每个点度数比较小，unordered_map 常数大（特别在频繁插入删除的情况下），而 map 更稳定，别人实测 map 更优（而且更好写，不用重载运算符）。

对于叠合重边，我们在 add 函数里处理，这样极大地简化了代码。

常见数据范围

如果题目保证了广义串并联图，例如上面说的树/仙人掌等，显然可以用。

如果数据范围保证 m≤n+km\le n+km≤n+k，kkk 比较小，也可以用广义串并联方法，最后图一定 n≤2kn\le 2kn≤2k，m≤3km\le 3km≤3k。这是广义串并联图的一个经典数据范围。

证明

压缩过程中，删 111 度点与缩 222 度点都删除了一条边和一个点，叠合重边删除了 111 条边，故 m−nm-nm−n 单调不升。

无法压缩时，每个节点均满足 degu≥3deg_u\ge 3degu​≥3，故 2m≥3n2m\ge 3n2m≥3n。结合 m≤n+km\le n+km≤n+k 解得 n≤2kn\le 2kn≤2k，m≤3km\le 3km≤3k。
