Hash 学习笔记

前言

本文主要讲得是如何防止卡哈希。

因为我在做 此题 时被卡得很惨。

以下讲得都是使用于 OI 的，CF 则更加严格。

单模 Hash

根据生日悖论，有 nnn 个字符串，模数为 ppp，那么冲突的概率是

P(conflict)=1−d!dn(d−n)!≈1−e−n(n−1)2pP(\text{conflict})=1-\frac{d!}{d^n(d-n)!}\approx 1-e^{-\frac{n(n-1)}{2p}} P(conflict)=1−dn(d−n)!d!​≈1−e−2pn(n−1)​

当 n>pn>\sqrt{p}n>p​ 时，冲突的概率约为 39.347%39.347\%39.347%，这个概率已经非常大了，相当于致命。

所以对于 10910^9109 级别的单模 hash，3×1043\times 10^43×104 就到了它的根号，所以随随便便被卡，甚至 n=105n=10^5n=105 时就近似 100%100\%100% 了。

所以 10910^9109 的单哈希连随机数据都可以轻松卡掉。

因此我们千万不要选取 10910^9109 级别的单模 hash。

那么我们只能用 101810^{18}1018 级别，即 long long 类型的了，只要差不多是这个级别的，概率就微乎其微了。

但是要注意一点，很多人（包括我）喜欢用自然溢出 hash，好处是好写，快速。

但是它有特定的办法卡，可以用分类讨论和 Thue-Morse 序列卡，所以求稳的话也不安全。

双模 Hash

  1. 我用一个自然溢出和一个 10910^9109 单模行不行？

    我的看法是不太好，如果它存心想卡自然溢出，且把所有字符串都卡自然溢出，那么那个自然溢出就相当于废掉了，也就是说你实际用的只是一个 10910^9109 的单模 hash。因此不妥。

  2. 我用两个 10910^9109 单模行不行？

    按理来说肯定强度肯定是杠杠的，但是竟然有特例。

    你还别说，真有卡这样的 题目。我一个 107051122310705112231070511223 和 4×109+74\times 10^9+74×109+7 都被卡得 很惨。

    根据那道题的教训，我再也不写两个单模 hash 了。

避免卡 Hash

根据上面的，我们如果要单模 hash 的话，要选自然溢出以外的 101810^{18}1018 级别的模数。

如果我们要双模 hash 的话，就不选上面说的方法。

这里推荐一个 101810^{18}1018 级别的梅森模数：261−12^{61}-1261−1。

不仅它的级别到了，它的计算方式也有一个小小优化。

对于 d=a⋅bmod  p,c=a⋅bd=a\cdot b\mod p,c=a\cdot bd=a⋅bmodp,c=a⋅b，，我们考虑 ccc 高于 616161 位的部分和小于等于 616161 位的部分。

首先有 261≡1(mod261−1)2^{61}\equiv1\pmod {2^{61}-1}261≡1(mod261−1)，ccc 高于 616161 位的部分可以看作 x×261x\times 2^{61}x×261。

那么 x×261≡x(mod261−1)x\times2^{61}\equiv x\pmod{2^{61}-1}x×261≡x(mod261−1)，因此 ccc 高于 616161 位的部分的贡献就是 xxx，可以用移位来实现。

因此 ddd 等于 xxx 加 ccc 的后 616161 位，大于 ppp 就减去一个 ppp。同时 ccc 的后 616161 位刚好就等于与上 ppp，因为 ppp 刚好都是 111。

选取基数

基数选择也对碰撞概率有影响。首先基数应该至少和字符集一样大，其次优质基数应满足三大特征：

  1. 与模数互质：若模数为质数，则基数只需非其倍数。互质可以避免出现周期性重复，最大化利用值域空间（如 base=2base=2base=2 时哈希值奇偶性固定）。

  2. 远离模数的二次剩余：防止出现 basek≡1(modp)base^k\equiv 1\pmod pbasek≡1(modp) 的短周期。例如 base=10base=10base=10 与 p=109+7p=10^9+7p=109+7 的组合周期仅为 p−1p-1p−1，实际效果差。

  3. 高熵分布：推荐使用不规则大质数。

优质基数可将冲突率再降一个数量级。

一般都选用 131,13331,13131,31,39,233,233331131,13331,13131,31,39,233,233331131,13331,13131,31,39,233,233331 等。

总结

根据上面的分析，在做 hash 的题目的时候，一个模数要用 261−12^{61}-1261−1，可以就这样用单模 hash，也可以在此基础上加上一个自然溢出或 107051122310705112231070511223 之类的模数，变成双模 hash，根据时间限制和自己的需要来吧。

当然也可以用非模 hash。
