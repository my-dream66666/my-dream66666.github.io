题意简述

给定整数 n,a,bn,a,bn,a,b。请判断是否存在一个 (0,1,…,2n−1)(0,1,\ldots, 2^n-1)(0,1,…,2n−1) 的排列 (p0,p1,…,p2n−1)(p_0,p_1,\ldots,p_{2^n-1})(p0​,p1​,…,p2n−1​)，满足以下所有条件。如果存在，请构造出一个解。

  • p0=ap_0 = ap0​=a。
  • p2n−1=bp_{2^n-1} = bp2n−1​=b。
  • 对于所有 0≤i<2n−10 \leq i < 2^n-10≤i<2n−1，pip_ipi​ 和 pi+1p_{i+1}pi+1​ 的二进制表示恰好只有一位不同。

1≤N≤171 \leq N \leq 171≤N≤17。

做法

容易发现 pip_ipi​ 二进制中 111 的个数是奇偶变化的，由于 ppp 的长度是 2n2^n2n，所以会变化 2n−12^n-12n−1 次。

易知 2n−12^n-12n−1 是奇数，所以只要 a⊕ba\oplus ba⊕b 的 111 的个数是偶数就无解。

但是如果是奇数呢？只要我们构造出一种方案那不就 100%100\%100% 有解了。

个人感觉这种构造不是人能想出来的。

容易知道 a,ba,ba,b 至少有一位不一样，令任意一位为 xxx，如果不考虑第 xxx 位，那么 a,ba,ba,b 的 111 的个数差就是偶数。

此时再将 aaa 异或 2k2^k2k（kkk 没有被考虑过），得到 midmidmid，那么 (a,mid)(a,mid)(a,mid)，(mid,b)(mid,b)(mid,b) 之间 111 的个数差为奇数。

这样就可以递归处理，而且 midmidmid 的第 xxx 位在递归左边时继承 aaa 的值，递归右边时继承 bbb 的值。

不难发现这样一定会到达终点，到达终点就输出 a,ba,ba,b，这 a,ba,ba,b 一定满足条件。

可以看到 a,ba,ba,b 递归下去后输出若干个数，其中最左边输出 aaa，最右边输出 bbb，所以递归下去输出 a⋯mid⋯mid′⋯ba\cdots mid\cdots mid^\prime\cdots ba⋯mid⋯mid′⋯b。

因为 mid,mid′mid,mid^\primemid,mid′ 符合条件，所以整体符合条件，而左右两边的输出不边，这应该是此题构造的突破口，这样一边制造不同，一边保证相同实在太妙了。
