Coudflare 配置

前言

Cloudflare 在 OI 界最著名的莫过于 CF 盾，但是此处介绍的是一些其他的东西。当然都是免费的。

域名配置 CDN

Cloudflare 在全球都有节点，所以 CDN 还是很快的，连接上可以其加速和保护作用。

具体的，先注册一个账号，需要一个邮箱，然后其他的就随便写，我注册的是美国的账户。

然后添加域名，选择 Free，然后一直搞下去，出现 N1 和 N2，把它填写在注册自己域名那里，自己域名的 CDN 就大功告成了。

部署博客到 Cloudflare Pages

本来我的 hexo 博客是用 Github Pages，但是因为我要加密码并且使用了自定义域名，所以用 Cloudflare Workers 会造成死循环问题。因此我把它迁移到了 Cloudflare Pages 上。

Cloudflare 上操作

点击 Workers and Pages，然后创建应用程序，选择连接 Github，然后就能弄到自己仓库。

它会让你填写一些东西，你只用填“构建命令”和“构建输出项目”，分别写 hexo generater 和 public 就行，这就和我们原来的 hexo 保持一致，避免遗忘。

然后可以绑定自定义域名，也就是我们第一个作用中提到的。

对于原来的博客呢，它不是也可以自定义域名吗。确实，我把它也自定义为那个域名，他的 CNAME 是写在 source 文件夹中。

在实际访问时，访问的还是 Cloudflare Pages 的页面，因为两个 CNAME 有个优先级，Github 上的优先级低一些（毕竟我的域名都在 Cloudflare 上）。

设置密码

我给我的网站设置了密码，这个 Cloudflare Pages 太良心了，可以直接在 hexo 的目录下新建 functions 文件夹，并在其下建立 _middleware.js 文件，让 AI 写一个 JS 就行了，不需要使用 Workers。

但是为了有尝试次数超过限制有锁定 IP 功能，还需要使用 “存储与数据库”中的 Workers KV，新建一个就行。

然后在 Workers and Pages 下的自己的仓库的设置找到 Bindings，加入那个 KV，把 KV namespace 和 Variable name 告诉 AI。

免费 VPN

Cloudflare WARP 现在改名成 Cloudflare One Client，搭配 Cloudflare Zero Trust 可以实现无限流量的免费 VPN，可以畅通访问 YouTube，Google.com，Twitter，Github，greasyfork 等网站，我认为是最 NB 的一个功能。

注册 Zero Trust

首先最难的是弄一个 Zero Trust，他会让你绑定银行卡，这里可以使用假的信息，具体见 这个。

这个 检验银行卡信息是否正确合法，它显示 Unknown 或 Live 就是能够使用的。这个 用来生成银行卡 BIN 可以填写 622759531087，我是用这个过的，CVV 填写一个三位数，我写的是 153，DATA 肯定要超过目前时间，我选的是 2030。生成 505050 个测试就行，一般会出现几个 Unknown。

虚拟人名、地址、邮编在网上找一个生成网站就好，但是我试了几次，都太假了，显示错误。所以我用 Deepseek 弄了一个可靠的地址、邮编。

这一步就应该可以轻松通过了。

下载 Cloudflare One Client

打开 Zero Trust 页面，在左侧栏中选择 integrations（集成），点击服务提供商，在最下面那个方框点击“加入一个设备”，然后就会有 777 个步骤。

先按照第一步下载最新版本，第二步填写一个可用邮箱，剩下的选择默认的就行。

然后打开下载好的 Cloudflare One Client，不要在上面的步骤搞好前就注册，不然会出现 Enrollment request is invalid。选择 Cloudflare 那个注册方式，填写自己的团队名，Zero Trust 的主页面的 Account Details 就有，可以在设置里更改。这样就会注册成功。

一些 Bug

连接时可能会出现：正在连接，正在使用 Happy eyeballs 算法。进度一直卡在 26%26\%26%，根据 这个，打开 Zero Trust，点击 Team and Resources，选择 Device，点击 Device Profiles，在 General profiles 中点击我们我们刚注册设备旁边的三个点，选择 Configure，在 Device tunnel protocol 从 WireGuard 改成 MASQUE，滑到最下面点击 Save profile。

我还对网络设置进行了操作，右键自己电脑网络上那个图标，打开“网络和 Internet 设置”，在高级网络设置选择“适配器选项”，右键点击自己电脑的那个网，选择属性，把 Internet 协议版本 6（TCP/IPv6）的勾划掉，保存以下即可。因为据说好像 IPv6 会拖慢其速度，因为中国大陆的某些原因？到时候可以试一下不改这个行不行。

做完这些后可能还是无法成功，需要耐心等待一段时间，我好像差不多 101010 分钟后就突然好了吧。

参考资料：Cloudflare WARP 免费安全网络复活了！Zero Trust 最新完整设置教程。

现在终于有一个无限免费好用的类 VPN（因为 IP 还是不变的），效果非常好，速度和稳定性都可以。
