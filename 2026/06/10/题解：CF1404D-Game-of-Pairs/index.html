题目

题目描述

这是一个交互题。

给定一个固定的正整数 nnn。有两位玩家，First 和 Second，按照如下规则进行游戏：

  1. First 取 2n2n2n 个数 1,2,…,2n1, 2, \dots, 2n1,2,…,2n，并将它们任意分成 nnn 个不相交的数对。
  2. 然后，Second 从 First 划分出的每一对中各选出一个数（可以任意选择）。

为了决定游戏的胜者，我们计算 Second 选出的所有数的和。如果这些数的和是 2n2n2n 的倍数，则 Second 获胜；否则 First 获胜。

你将获得整数 nnn。你的任务是决定你想扮演哪一位玩家，并赢得这场游戏。

输入格式

交互开始时，首先读入一个整数 nnn（1≤n≤5⋅1051 \le n \le 5 \cdot 10^51≤n≤5⋅105）。

读入后，输出一行，内容为 First 或 Second，表示你选择扮演哪一位玩家。之后的交互流程取决于你的选择：

  • 如果你选择扮演 First，输出一行 2n2n2n 个整数 p1,p2,…,p2np_1, p_2, \dots, p_{2n}p1​,p2​,…,p2n​，表示数字 iii 属于第 pip_ipi​ 个数对，1≤i≤2n1 \le i \le 2n1≤i≤2n。其中 1≤pi≤n1 \le p_i \le n1≤pi​≤n，且每个 111 到 nnn 的数字恰好出现两次。

  • 如果你选择扮演 Second，交互器会输出 2n2n2n 个整数 p1,p2,…,p2np_1, p_2, \dots, p_{2n}p1​,p2​,…,p2n​，表示数字 iii 属于第 pip_ipi​ 个数对。你需要输出一行 nnn 个整数 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​，每个数对中恰好选出一个数字。

无论你选择扮演哪一方，交互器最后会输出一个整数：如果你的答案正确（即你扮演 First 时，Second 无法选出和为 2n2n2n 的倍数的方案，或你扮演 Second 时，你选出的数的和是 2n2n2n 的倍数），则输出 000；否则输出 −1-1−1。特别地，如果你选择扮演 First 并失败，交互器不会输出 Second 选出的数字。无论哪种情况，你的程序都应在读入该数字后立即终止。

如果你在交互过程中进行了非法操作，交互器会输出 −1-1−1 并结束交互。你将收到 Wrong Answer 判定。请确保在读入该数字后立即终止程序，以避免获得其他判定。

每次输出后不要忘记输出换行并刷新输出缓冲区，否则会收到 Idleness limit exceeded 判定。具体做法如下：

  • C++：fflush(stdout) 或 cout.flush()
  • Java：System.out.flush()
  • Pascal：flush(output)
  • Python：stdout.flush()
  • 其他语言请参考相关文档。

题意简述

给定一个固定的正整数 nnn。有两位玩家，A 和 B，按照如下规则进行游戏：

  1. A 取 2n2n2n 个数 1,2,…,2n1, 2, \dots, 2n1,2,…,2n，并将它们任意分成 nnn 个数对。

  2. 然后，B 从 A 划分出的每一对中各选出一个数（可以任意选择）。

为了决定游戏的胜者，我们计算 B 选出的所有数的和。如果这些数的和是 2n2n2n 的倍数，则 B 获胜；否则 A 获胜。

你将获得整数 nnn。你的任务是决定你想扮演哪一位玩家，并赢得这场游戏。

如果选择 A，给出划分使 B 无法获胜。

如果选择 B，将获得这些数对，并且输出获胜的方案。

1≤n≤5×1051 \le n \le 5 \times 10^51≤n≤5×105。

所以对于一个 nnn，绝对有且仅有一个一定获胜的选择，这个选择一定只和 nnn 有关。
