Takahashi’s goal is to increase the number of occurrences of ABC as a substring of SSS by exactly KKK , by replacing some characters of SSS .

Determine whether this is possible, and if so, find the minimum number of characters Takahashi needs to replace to achieve his goal.

TTT test cases are given; solve each one.

For each test case, if it is impossible for Takahashi to achieve his goal, output −1-1−1 ; otherwise, output the minimum number of characters that need to be replaced to achieve his goal.

说明/提示

Sample Explanation 1

In the first test case, the given string S=S=S= ATCABC contains ABC as a substring once.
Replacing the second character of SSS with B gives S=S=S= ABCABC, which contains ABC as a substring twice.
Thus, replacing one character increases the number of occurrences of ABC as a substring by 111 , achieving the goal. Therefore, output 111 on the first line.

In the second test case, the given string S=S=S= ABABC contains ABC as a substring once; no matter how the characters of SSS are replaced, it is impossible to make SSS contain ABC as a substring twice.
Therefore, output −1-1−1 on the second line.

In the third test case, the given string S=S=S= XABCYZ contains ABC as a substring once.
To make SSS contain ABC as a substring twice, all characters of SSS must be replaced, giving S=S=S= ABCABC.
Therefore, output 666 on the third line.

Constraints

  • 1≤T≤1051\leq T\leq 10^51≤T≤105
  • SSS is a string of length between 333 and 3×1053\times 10^53×105 , inclusive, consisting of uppercase English letters.
  • 1≤K≤101\leq K \leq 101≤K≤10
  • In each input, the total length of SSS over all test cases is at most 3×1053\times 10^53×105 .
  • TTT and KKK are integers.

题意简述

一个长度为 nnn 的只含大写字母的字符串 SSS，问最少替换多少个字符，使得子段 ABC\texttt{ABC}ABC 的数量增加 kkk。

3≤n≤3×1053\le n\le 3\times 10^53≤n≤3×105，1≤k≤101\le k \le 101≤k≤10。
