题意简述

给你一个 1∼n1 \sim n1∼n 的排列 PPP ,你可以进行若干次如下操作，也可以不进行操作。

  • 每次选择一个整数 iii (1 ≤ i ≤ n−11\ \leq\ i\ \leq\ n-11 ≤ i ≤ n−1) ，使 v=max⁡(Pi,Pi+1)v=\max(P_i,P_{i+1})v=max(Pi​,Pi+1​) ，然后将 PiP_iPi​ 和 Pi+1P_{i+1}Pi+1​ 改为 vvv 。

求问最后可能得到多少种不同的结果，答案对 998244353998244353998244353 取模。

2 ≤ n ≤ 50002\ \leq\ n\ \leq\ 50002 ≤ n ≤ 5000。

做法

从左往右考虑，令 lil_ili​ 为 iii 位置上的数最多能覆盖到的最左端，rir_iri​ 同理。

令 fi,jf_{i,j}fi,j​ 为考虑了前 iii 个位置，覆盖的区间为 [1,j][1,j][1,j] 的方案数（容易知道覆盖的区间的左端点一定是 111，并且一定是连续的，因此这样设合法）。

转移到 iii 自然就需要考虑 iii 位置上覆盖的区间范围，而容易知道它可以覆盖 [li,ri][l_i,r_i][li​,ri​] 任意子区间。

因为无论如何，它都可以先覆盖 [li,ri][l_i,r_i][li​,ri​]，然后被它左右两边比它大的再覆盖。

因此我们可以得出转移方程：

fi,j=∑k=li−1j−1fi−1,kf_{i,j}=\sum_{k=l_i-1}^{j-1}f_{i-1,k} fi,j​=k=li​−1∑j−1​fi−1,k​

可以用前缀和优化，得到：

fi,j=fi,j−1+fi−1,j−1f_{i,j}=f_{i,j-1}+f_{i-1,j-1} fi,j​=fi,j−1​+fi−1,j−1​

发现空间不够，用滚动数组优化即可，可以得到一个很简单的转移。

是否使用单调栈预处理 li,ril_i,r_ili​,ri​，时间复杂度都是 O(n2)\mathcal O(n^2)O(n2)。
