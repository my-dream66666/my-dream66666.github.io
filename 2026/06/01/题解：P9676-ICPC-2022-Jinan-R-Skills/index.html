题解：P9676 [ICPC 2022 Jinan R] Skills

前言

题目传送门。

性质题。

▶
题目

题目描述

庞博士有 333 项技能：喝汽水、猎狐和炒股，编号分别为 1,2,31,2,31,2,3。初始时，每项技能的熟练度为 000。

接下来有 nnn 天。在第 iii 天，庞博士可以选择一项技能（假设是第 jjj 项）进行练习，然后在这天结束时让这项技能的熟练度增加 ai,j(0≤ai,j≤10000)a_{i,j}(0\leq a_{i,j}\leq 10000)ai,j​(0≤ai,j​≤10000)。同时，如果某一项技能（假设是第 kkk 项）已经有 xxx 天没有练习，那么在这天结束时，这项技能的熟练度会减少 xxx。当然，任何一项技能的熟练度都不可能小于 000。

现在，庞博士想知道：在第 nnn 天结束后，这 333 项技能的熟练度之和最大为多少。由于他非常忙，而且他的日程和对习惯的适应程度可能有变，所以庞博士把这 TTT 个问题交给了你——每个问题的内容都一样，只是给出的数据可能有所不同而已。

输入格式

第一行，一个正整数 T (1≤T≤1000)T~(1 \leq T \leq 1000)T (1≤T≤1000)，表示数据组数。

对于每组数据，输入 (n+1)(n + 1)(n+1) 行。

  • 第一行，一个正整数 n (1≤n≤1000)n\ (1 \leq n \leq 1000)n (1≤n≤1000)，表示天数。
  • 第 i+1i + 1i+1 行，包含三个正整数 ai,1,ai,2,ai,3 (0≤ai,j≤10000, ∀1≤i≤n, 1≤j≤3)a_{i, 1}, a_{i, 2}, a_{i, 3}\ (0 \leq a_{i, j} \leq 10000,\ \forall 1 \leq i \leq n,\ 1 \leq j \leq 3)ai,1​,ai,2​,ai,3​ (0≤ai,j​≤10000, ∀1≤i≤n, 1≤j≤3)。

数据保证单个测试点内的 ∑n\sum n∑n 不超过 100010001000。

输出格式

对于每组数据，输出 111 行 111 个数，表示答案。

输入 #1

输出 #1

题意简述

有 333 项技能，在 nnn 天中，每天只能练习一项。若第 iii 天练习第 jjj 项，则第 jjj 项的熟练度会增加 ai,ja_{i,j}ai,j​。如果有连续 kkk 天没有练习某一项，那么该项的熟练度会在这天减少 kkk（如果减少到 000 就不会继续减少）。求出最终 333 项技能的熟练度之和最大为多少。

1≤n≤1031\le n\le 10^31≤n≤103，0≤ai,j≤1040 \leq a_{i, j} \leq 10^40≤ai,j​≤104。

做法

Step One

直接 DP，令 fi,j,k,pf_{i,j,k,p}fi,j,k,p​ 为第 iii 天练习第 ppp 项，其余两项分别有 j,kj,kj,k 天没练的熟练度之和的最大值。

其余两项的的编号分别是 p+1,p+2p+1,p+2p+1,p+2 模 333（以 000 为初始下标），下文下标都是在模 333 的意义下。

不难得出以下转移：

继续练习第 ppp 项：

fi,j,k,p←fi−1,j,k,p+ai,p−j−kf_{i,j,k,p}\gets f_{i-1,j,k,p}+a_{i,p}-j-k fi,j,k,p​←fi−1,j,k,p​+ai,p​−j−k

练习 p+1p+1p+1 项：

fi,k,1,p+1←fi−1,j,k,p+ai,p+1−k−1f_{i,k,1,p+1}\gets f_{i-1,j,k,p}+a_{i,p+1}-k-1 fi,k,1,p+1​←fi−1,j,k,p​+ai,p+1​−k−1

练习 p+2p+2p+2 项：

fi,1,j,p+2←fi−1,j,k,p+ai,p+2−j−1f_{i,1,j,p+2}\gets f_{i-1,j,k,p}+a_{i,p+2}-j-1 fi,1,j,p+2​←fi−1,j,k,p​+ai,p+2​−j−1

但是我们没有考虑某一项减少到负数的情况，不着急，下面会进行阐述。

这样的时间复杂度为 O(n2)\mathcal O(n^2)O(n2)。

Step Two

考虑优化，直接从 DP 本身入手不太容易优化，因此考虑题目性质。

我们不难感受到如果一项长时间没练，那么它的熟练度减少的速度越来越大。经过计算，可以发现最多连续 2V2\sqrt{V}2V​ 天没有练习（V=max⁡{ai,j}V=\max\{a_{i,j}\}V=max{ai,j​}），上一次练习的收益会变成 000，这样一定是不优的。

因此我们可以将 j,kj,kj,k 的上界变成 2V2\sqrt V2V​ ，时间复杂度为 O(nV)\mathcal O(nV)O(nV)。

对于如果某一项减少到负数，根据上面的分析，这样是不优的，因此不会影响到最终答案。

唯一需要考虑的是某一项没有开始练习，我们不能减去 j,kj,kj,k。这里用 j,k=0j,k=0j,k=0 来表示没有开始练习，然后转移的时候特判一下就行了。

但是计算发现空间有点紧张，所以用滚动数组优化。
