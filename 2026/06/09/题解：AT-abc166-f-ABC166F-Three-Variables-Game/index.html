题解：AT_abc166_f [ABC166F] Three Variables Game

题目

题目描述

在某个游戏中，有三个变量，分别用 AAA、BBB、CCC 表示。

随着游戏的进行，你需要进行 NNN 次选择。每一次选择由字符串 sis_isi​ 表示，当 sis_isi​ 为 AB 时，表示你可以选择给 AAA 或 BBB 加 111，同时从另一个变量减去 111；当 sis_isi​ 为 AC 时，表示你可以选择给 AAA 或 CCC 加 111，同时从另一个变量减去 111；当 sis_isi​ 为 BC 时，表示你可以选择给 BBB 或 CCC 加 111，同时从另一个变量减去 111。

在每一次选择之后，AAA、BBB、CCC 的值都不能为负数。

请判断是否存在一种选择方式，使得能够完成全部 NNN 次选择且始终满足上述条件。如果存在，请给出一种可行的选择方案。

输入格式

输入以如下格式从标准输入读入：

NNN AAA BBB CCC
s1s_1s1​
s2s_2s2​
⋮\vdots⋮
sNs_NsN​

输出格式

如果存在一种选择方式能够完成全部 NNN 次选择且始终满足条件，则输出 Yes，否则输出 No。

如果输出 Yes，则在接下来的 NNN 行中，依次输出每次选择中被加 111 的变量名（A、B 或 C）。

限制条件

  • 1≤N≤1051 \leq N \leq 10^51≤N≤105

  • NNN、AAA、BBB、CCC 均为整数

样例解释 1

可以如下完成全部 222 次选择：

  • 第 111 次选择时，给 AAA 加 111，从 BBB 减 111。此时 AAA 变为 222，BBB 变为 222。
  • 第 222 次选择时，给 CCC 加 111，从 AAA 减 111。此时 CCC 变为 111，AAA 变为 111。

题意简述

有三堆石子，分别有 a,b,ca,b,ca,b,c 个。共有 nnn 次操作，每次操作指定两堆石子，你需要将一堆中的一个石子转移到另一堆上。

如果能进行 nnn 次操作，构造一个合法的方案。

做法

要使操作尽可能多，肯定是尽可能均摊，就是多的石堆向少的转移。

这时候我们发现如果石子的数量和 ≤3\le 3≤3，一定存在操作。当然除非第一次就是不能。（以下不讨论这种情况）

因为如果不能存在操作就意味着，操作对象都是 000，等价于另一个独占 333 个，但是我们是尽可能均摊操作，所以不可能所有石子都在一堆，这很好理解。

所以说我们要处理的是石子数量和 ≤2\le 2≤2，动态规划当然可行，但是更简单的方法是离线处理。

我们可以看到下一个的操作，所以此次操作的分配不能使下一次操作都为 000，例如此次操作 A,BA,BA,B，下一次操作 B,CB,CB,C，那么这次就要将石子转移到 BBB 上。容易发现这样一定可以完成所有操作。

所以根据上面的分析直接模拟即可。
