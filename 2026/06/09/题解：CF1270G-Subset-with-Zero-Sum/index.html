题意简述

给定 nnn 个整数 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​，其中对于每个 1≤i≤n1 \le i \le n1≤i≤n，都有 i−n≤ai≤i−1i-n \le a_i \le i-1i−n≤ai​≤i−1。

请找出这 nnn 个整数中的某个非空子集，使得其元素之和等于 000。在给定的约束下，可以保证一定存在这样的子集。

1≤n≤1061 \le n \le 10^61≤n≤106。

做法

子集数量太多了，只能从限制入手，i−n≤ai≤i−1i-n \le a_i \le i-1i−n≤ai​≤i−1 很自然转化成 1≤i−ai≤n1\le i-a_i\le n1≤i−ai​≤n。

我们要 ∑ai=0\sum a_i=0∑ai​=0，相当于 ∑(i−ai)−∑i=0\sum(i-a_i)-\sum{i}=0∑(i−ai​)−∑i=0。

这时想到了什么，i−aii-a_ii−ai​ 和 iii 的范围都是 [1,n][1,n][1,n]，非常符合下标，然后上面的式子又是减号，一个神奇的操作来了。

将点 iii 向点 i−aii-a_ii−ai​ 连有向边，nnn 个点，nnn 条边，每个点出度为 111，一定会形成一个环，惊奇地发现这个环上满足 ∑(i−ai)−∑i=0\sum(i-a_i)-\sum{i}=0∑(i−ai​)−∑i=0，这题就做完了。

找环的方式很简单，无需显式建边，从 111 开始遍历，找到第一个闭合点，再从闭合点开始遍历，再次到闭合点，这就是一个环。

111 不一定在环上，例如 1→2→⋯→n→21\to 2\to \cdots\to n\to 21→2→⋯→n→2。
