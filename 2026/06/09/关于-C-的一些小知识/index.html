关于 C++ 的一些小知识

  1. 使用 map 函数 [ ] 查找 key 时，系统会自动加入这个 key 并赋初始值为0，但用 find 函数或 count 会避免这种情况。\\[1.5em]

  2. 用 memset(a,0x3f,sizeof(a)) 赋值时只能赋整数数组，若要给小数数组赋初始值，必用 127127127（对应 0x7f ）不能用 636363（对应 0x3f）这个数字，因为实际中用 636363 得到的数字太小了，比 1 小得多，而且用 127127127 不会爆掉，得到的数字也大得多(远超 int 范围)；\\[1.5em]

  1. 关于递归栈的空间开销
    每递归一层，就会新分配一个帧用于空间开销。
    递归栈的每一层的空间开销可以分成几个部分：

    • 函数参数。（不用多说）

    • 返回地址。 （返回地址+返回值储存区）

    • EBP\texttt{EBP}EBP 指针。（每一层必有 444 字节）

    • 函数的局部变量。 （不必多说）

  3. 快速模模板。

    方法是 barrett 约减。

    原理如下：

    对于 xxx 与 模数 MMM，我们有

    xM=x2k×2kM≈x2k×⌊2kM⌋\frac{x}{M}=\frac{x}{2^k}\times\frac{2^k}{M}\approx\frac{x}{2^k}\times\left\lfloor\frac{2^k}{M}\right\rfloor Mx​=2kx​×M2k​≈2kx​×⌊M2k​⌋

    事实上，

    • 当 2k>x2^k>x2k>x 时，误差 ≤1\le 1≤1。

    • 当 2k>x×(M−1)2^k>x\times(M-1)2k>x×(M−1) 时，⌊xM⌋=⌊x×I2k⌋\left\lfloor\frac{x}{M}\right\rfloor=\left\lfloor\frac{x\times I}{2^k}\right\rfloor⌊Mx​⌋=⌊2kx×I​⌋，即误差为 000.

    通常情况下我们取 k=64k=64k=64，即误差 ≤1\le 1≤1 的情况。

    I=⌊2kM⌋I=\left\lfloor\frac{2^k}{M}\right\rfloor I=⌊M2k​⌋

    那么

    x mod M=x−⌊x×I2k⌋x \bmod M=x-\left\lfloor\frac{x\times I}{2^k}\right\rfloor xmodM=x−⌊2kx×I​⌋

  3. 关于 STL 的 insert,erase 函数，它们都有返回值。

      1. 对于 set,map 等 STL，insert 返回的是 pair 类型，first 代表插入元素所在的迭代器，second 是一个 bool 类型，true 代表成功插入，false 代表没有。

      2. 对于 vector,list 这种顺序容器，insert 返回的就是插入元素所在的迭代器。

      1. 对于 vector 和 set 用迭代器删除元素，erase 返回的是最后一个被删除的元素的下一个迭代器。

      2. 对于 set 用 key 来 erase，返回的就是被删除元素的数量（虽然 set 永远是 0/10/10/1，但是 multiset 就不一样了）。

  4. float 和 double 的区别：

    • float 类型占用 ‌444 个字节（323232 位）‌ 的内存，double 类型占用 ‌888 个字节（646464 位）‌ 的内存。

    • float 类型精度约为 ‌666 到 777 位十进制数字‌，
      double 类型精度约为 ‌151515 到 161616 位十进制数字‌。

    • float 类型数值范围大约是 ‌±3.4×1038\pm 3.4 \times 10^{38}±3.4×1038，double 类型数值范围大约是 ‌±1.7×10308\pm 1.7 \times 10^{308}±1.7×10308。

    • 在 C/C++ 等语言中，默认的小数是 double 类型，如果要使用 float 类型，需要在数字后加上 f 或 F 后缀，或者进行强制类型转换。

    • float 类型由符号位、指数位（888 位）和尾数位（232323 位）组成，double 类型由符号位、指数位（111111 位）和尾数位（525252 位）组成。

    在某些处理器上，float 的运算速度可能更快，但是现代 CPU 通常对 double 运算也进行了优化，因此速度差异并不显著。

    所以 float 在 OI 中的应用场景就是在卡空间或卡常的情况下可能使用。个人感觉还是没啥用。\\[1.5em]

  5. 我们经常会用一种 ±mod\pm mod±mod 的方式进行快速取模，但是我们还有一种更快的方法对其优化卡常。

    对于负数取模，可以这样做：a+=a>>31&mod，首先执行 a>>31。

    • 如果 a<0a<0a<0，那么 a>>31 就是 −1-1−1。因为如果符号位是 111，那么向右移是补 111 的，−1-1−1 的二进制全是 111，−1∧mod-1\land mod−1∧mod 就会得到 modmodmod，因此就相当于 a+=mod。

    • 如果 a≥0a\ge 0a≥0，那么 a>>31 就是 000，0∧mod0\land mod0∧mod 就是 000，因此相当于 a+=0，对 aaa 没有影响。

    又因为位运算比条件判断语句要快，所以这个可以加速处理负数的取模。\\[1.5em]

    既然这样，我们也可以有一种方法来加速正数的取模，例如 a+=b，之后，对 aaa 取模，那么我们可以 a+=b-mod，然后用上面一个式子进行取模。\\[1.5em]
