题解：CF643G Choosing Ads

前言

比较妙的一道题。

题目

题目描述

一位社交网络开发人员最近提出了一种为用户选择广告的新算法。

广告商可以购买 nnn 个时段。他们可以一次性购买一段连续的时段。拥有的时段越多，广告向用户展示的机会就越大。

每次需要选择要展示的广告时，都会通过一种秘密算法选出一些时段，然后再选择一些广告商。然而，要求所有在这个部分拥有至少 p%p\%p% 的时段的广告商必须全部被选中。

另一方面，用户不喜欢广告。因此，决定同时显示的广告商数量不得超过 ⌊100p⌋\lfloor \frac{100}{p} \rfloor⌊p100​⌋。请您根据上述规则开发一个销售时段段和选择广告商的系统。

输入格式

输入的第一行包含三个整数 n,m,pn,m,pn,m,p（1≤n,m≤150000,20≤p≤1001 \le n,m \le 150000,20 \le p \le 1001≤n,m≤150000,20≤p≤100）——时段数、系统查询次数和保证广告显示的阈值。

下一行包含 nnn 个整数 aia_iai​（1≤ai≤1500001 \le a_i \le 1500001≤ai​≤150000），其中第 iii 个数字表示当前拥有第 iii 个时段的广告商 ID。

接下来的 mmm 行包含查询描述。每个描述都是以下形式之一：

  • 1 l r id (1≤l≤r≤n, 1≤id≤150000)(1 \le l \le r \le n, 1 \le id \le 150000)(1≤l≤r≤n, 1≤id≤150000)：广告商 ididid 购买了从 lll 到 rrr（含）范围内的所有时段；
  • 2 l r (1≤l≤r)(1 \le l \le r)(1≤l≤r) - 您需要为段 [l, r][l, r][l, r] 选择广告商。

输出格式

对于第二种类型的每个查询，答案应单独打印一行。答案的第一个整数应为将显示的广告数量 (0≤cnt≤⌊100p⌋)(0 \le cnt \le \lfloor \frac{100}{p} \rfloor)(0≤cnt≤⌊p100​⌋)。接下来的 cntcntcnt 个整数应该是广告商的 ID。

允许不止一次打印同一个广告商，但所有至少拥有 ⌈p⋅(r−l+1)100⌉\lceil \frac{p \cdot (r-l+1)}{100} \rceil⌈100p⋅(r−l+1)​⌉ 个在 lll 到 rrr 段插槽的广告商，都应出现在答案中。

题意简述

  • 给定一个长度为 nnn 的序列和一个整数 ppp（全局）。
  • 有 mmm 个操作，操作要么是区间赋值，要么是询问区间内出现次数至少占 p%p\%p% 的数。
  • 输出询问的答案时，可以包含错的数，也可以重复输出，但对的数一定要在答案中，且输出的数的个数不超过 ⌊100p⌋\lfloor \frac{100}{p} \rfloor⌊p100​⌋。
  • 1≤n,m≤1.5×1051\le n,m \le 1.5 \times 10^51≤n,m≤1.5×105，20≤p≤10020 \le p \le 10020≤p≤100。

做法

Step One

先考虑 p>50p>50p>50 的情况，题目就变成了求出绝对众数（在可重集合中出现次数严格大于一半的元素）。

而求出绝对众数有一个时间复杂度 O(n)\mathcal O(n)O(n)，空间复杂度 O(1)\mathcal O(1)O(1) 的算法：摩尔投票法。

考虑不断加入一个数 xxx。首先有：

{cnt←cnt+1now=xcnt←cnt−1now≠x\begin{cases} cnt\gets cnt+1&now=x\\ cnt\gets cnt-1&now\neq x \end{cases} {cnt←cnt+1cnt←cnt−1​now=xnow=x​

然后此时如果 cnt<0cnt<0cnt<0，now←x,cnt←1。now\gets x,cnt\gets 1。now←x,cnt←1。

方法的正确性显然。因为令绝对众数为 MoMoMo，则它的数量大于其余数的数量，所以一一抵消后还剩下的就是 MoMoMo。

Step Two

因此我们继续扩展摩尔投票法，根据上面的分析，它的核心思想就是一一抵消，如果我们要选出出现次数至少占 p/100p/100p/100 的数呢。

每次选出互不相同的 ⌊100p⌋+1\lfloor\frac{100}{p}\rfloor+1⌊p100​⌋+1 个数，然后抵消，直到选不出 ⌊100p⌋+1\lfloor\frac{100}{p}\rfloor+1⌊p100​⌋+1 个数为止，剩下的数就是答案。

容易想到用线段树来维护，但是如何合并左右两个区间的信息呢？

还是考虑一一加入数，不妨将左子树加入到右子树中，每次加入节点都进行抵消。

抵消的方式就是求出当前集合出现次数最小的 minnminnminn，然后将所有数的次数减去 minnminnminn，然后将当前集合更新为出现次数 >0>0>0 的数。

令 k=⌊100p⌋k=\lfloor\frac{100}{p}\rfloork=⌊p100​⌋，合并的时间复杂度就是 O(k2)\mathcal O(k^2)O(k2)。

因此时间复杂度就是 O(nk2log⁡n)\mathcal O(nk^2\log n)O(nk2logn)，视 n,mn,mn,m 同阶。
