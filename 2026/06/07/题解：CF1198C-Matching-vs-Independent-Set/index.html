题目

CF1198C Matching vs Independent Set

给定一个包含 3⋅n3 \cdot n3⋅n 个顶点和 mmm 条边的图。你需要找到一个大小为 nnn 的匹配，或者一个大小为 nnn 的独立集。

一组边称为匹配，当且仅当任意两条边没有公共端点。

一组顶点称为独立集，当且仅当任意两点之间都没有边相连。

输入格式

第一行包含一个整数 T≥1T \ge 1T≥1，表示你需要处理的图的数量。接下来是 TTT 个图的描述。

每个图的描述的第一行包含两个整数 nnn 和 mmm，其中 3⋅n3 \cdot n3⋅n 是该图的顶点数，mmm 是该图的边数（1≤n≤1051 \leq n \leq 10^{5}1≤n≤105，0≤m≤5⋅1050 \leq m \leq 5 \cdot 10^{5}0≤m≤5⋅105）。

接下来的 mmm 行，每行包含两个整数 viv_ivi​ 和 uiu_iui​（1≤vi,ui≤3⋅n1 \leq v_i, u_i \leq 3 \cdot n1≤vi​,ui​≤3⋅n），表示在顶点 viv_ivi​ 和 uiu_iui​ 之间有一条边。

保证图中没有自环和重边。

保证所有图中 nnn 的总和不超过 10510^{5}105，所有图中 mmm 的总和不超过 5⋅1055 \cdot 10^{5}5⋅105。

输出格式

对于每个图，输出一组答案。

如果你找到了一个大小为 nnn 的匹配，第一行输出 “Matching”（不带引号），第二行输出 nnn 个整数，表示匹配中边的编号。边按输入顺序编号，从 111 到 mmm。

如果你找到了一个大小为 nnn 的独立集，第一行输出 “IndSet”（不带引号），第二行输出 nnn 个整数，表示独立集中的顶点编号。

如果既没有大小为 nnn 的匹配，也没有大小为 nnn 的独立集，输出 “Impossible”（不带引号）。

边和顶点的输出顺序可以任意。

如果有多组解，输出任意一组即可。特别地，如果既存在大小为 nnn 的匹配，也存在大小为 nnn 的独立集，则你只需输出其中一种方案。

题意简述

给定一个包含 3×n3 \times n3×n 个顶点和 mmm 条边的图。你需要找到一个大小为 nnn 的匹配，或者一个大小为 nnn 的独立集。

一组边称为匹配，当且仅当任意两条边没有公共端点。

一组顶点称为独立集，当且仅当任意两点之间都没有边相连。

1≤n≤1051\le n\le 10^51≤n≤105，0≤m≤5×1050\le m \le 5\times 10^50≤m≤5×105。

做法

不难感受到这个 3n3n3n 有所玄妙，因为一个大小为 nnn 的匹配有 2n2n2n 个节点，大小为 nnn 的独立集有 nnn 个节点，而 3n=n+2n3n=n+2n3n=n+2n，这不是偶然。

不妨先考虑弄出一组匹配，不管它大小。

具体的，枚举每一条边 u→vu\to vu→v，如果 u,vu,vu,v 都未被标记过，那么加入这条边并标记 u,vu,vu,v。

这样我们可以得到一组匹配，如果这组匹配的大小 ≤n\le n≤n，此题就做完了。

如果这组匹配大小 <n<n<n，那么未被标记的点的个数 >n>n>n，并且它们恰好组成一个独立集。考虑反证法易证。
